## Key Concepts

- **Data** is information (numbers, facts, observations) collected about something
- Before data is useful, you must **collect**, **organise**, and **present** it clearly
- A **frequency table** organises data by listing categories and how many times each occurs
- A **pictograph** uses small pictures/icons to represent data; each icon stands for a set number of items
- The **scale** in a pictograph tells how many items each icon represents (e.g., 1 icon = 4 items)
- To read a pictograph: count the icons and **multiply by the scale**
- A **bar graph** uses rectangular bars to display data; the **height** of each bar shows the value
- Parts of a bar graph: **horizontal axis** (categories), **vertical axis** (values), **bars**, and **title**
- Bar graphs make **comparisons easier** because differences in bar heights are immediately visible
- The same data can be shown using different scales — the numbers stay the same
- To make a bar graph: gather data, pick a scale, draw axes, draw bars, label everything

## Important Definitions

| Term | Meaning |
|------|---------|
| **Data** | Information collected about something — numbers, facts, observations |
| **Pictograph** | A graph that uses pictures/icons to represent data |
| **Bar graph** | A graph that uses rectangular bars to represent data |
| **Scale** | How many items each picture or unit on the axis represents |
| **Horizontal axis** | The bottom line of a graph — usually shows categories |
| **Vertical axis** | The side line of a graph — usually shows numbers/values |
| **Frequency** | How many times something occurs |

## Pictograph vs Bar Graph

| Feature | Pictograph | Bar Graph |
|---------|-----------|-----------|
| Uses | Pictures or icons | Rectangular bars |
| Best for | Small, simple data | Larger data, easy comparison |
| How to read | Count icons x scale | Read bar height off the axis |

## Remember These

- In a pictograph, always check the **scale** before reading values — one icon may represent more than one item
- Bar graphs are better than pictographs for **comparing** values because height differences are easy to see
- Always **label both axes** and give your graph a **title**
- Half an icon in a pictograph means **half the scale value** (if 1 icon = 4, then half icon = 2)
