## Key Concepts

- **Commutative property**: changing the order of multiplication does not change the product (3 x 7 = 7 x 3)
- **Multiplying by 10**: put one zero at the end; **by 100**: two zeros; **by 1,000**: three zeros
- Multiplying two multiples of 10: multiply the non-zero parts, then attach all trailing zeros (40 x 30 = 1,200)
- **Distributive property (Break and Multiply)**: split one number into parts, multiply each, then add (16 x 7 = 10x7 + 6x7 = 112)
- **Grid/area model**: arrange the split multiplication in a grid to keep it organised
- **Doubling and halving**: double one number and halve the other — the product stays the same (24 x 5 = 12 x 10 = 120)
- **Nearest multiple strategy**: round to a nearby multiple of 10, multiply, then fix the error (6 x 19 = 6x20 - 6 = 114)
- For **3-digit x 1-digit**: break the 3-digit number into hundreds, tens, ones and multiply each
- For **3-digit x 2-digit**: multiply by ones digit, then by tens digit, and add the results
- Multiplication patterns: 11 x a two-digit number follows a quick trick (11 x 27 = 297)
- Exponential growth beats linear growth — multiplying by 4 daily grows far faster than doubling

## Important Definitions

| Term | Meaning |
|------|---------|
| **Product** | The answer you get when you multiply two numbers |
| **Commutative property** | Changing the order of multiplication does not change the product |
| **Distributive property** | Breaking a number into parts and multiplying each part separately |
| **Doubling** | Multiplying by 2 |
| **Halving** | Dividing by 2 |
| **Estimate** | Finding a rough answer by rounding |

## Remember These

- Doubling and halving works best when one number is **5, 25, or 50** (they become 10, 50, or 100)
- When using the nearest multiple strategy, **subtract** if you rounded up and **add** if you rounded down
- The **area model (grid)** is a reliable way to organise multi-digit multiplication without losing track
- Any number multiplied by **0** is always **0**
