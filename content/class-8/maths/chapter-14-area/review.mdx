## Key Concepts

- **Area** measures how much flat space a region occupies, counted in unit squares
- Area and perimeter are **independent** -- same perimeter can give different areas and vice versa
- A diagonal splits a rectangle into **two congruent triangles**, each with half the area
- The triangle area formula works for **all** triangle types (right, acute, obtuse)
- For obtuse triangles, the altitude falls **outside** the triangle but the formula still holds
- A **median** (vertex to midpoint of opposite side) splits a triangle into two equal-area triangles
- All triangles sharing the same **base** and between the same **parallel lines** have equal area
- A parallelogram can be transformed into a rectangle of equal area by cutting and rearranging
- A trapezium's area formula comes from joining two identical trapeziums to form a parallelogram
- Any polygon can be split into **triangles** to calculate its total area
- The **Shulba-Sutras** contain problems about reshaping figures while preserving area

## Important Definitions

| Term | Meaning |
|------|---------|
| Area | The amount of flat space enclosed by a figure, measured in square units |
| Base | Any chosen side of a triangle or parallelogram |
| Height (altitude) | The perpendicular distance from the base to the opposite vertex (or parallel side) |
| Trapezium | A quadrilateral with exactly one pair of parallel sides |
| Diagonal | A line segment connecting non-adjacent vertices of a polygon |

## Area Formulas

| Shape | Formula |
|-------|---------|
| Rectangle | length x width |
| Square | side² |
| Triangle | (1/2) x base x height |
| Parallelogram | base x height |
| Trapezium | (1/2) x (a + b) x h (where a, b are parallel sides) |
| Rhombus | (1/2) x d₁ x d₂ (product of diagonals) |
| General quadrilateral | (1/2) x diagonal x (h₁ + h₂) |

## Remember These

- The **height** of a parallelogram is the perpendicular distance between parallel sides, NOT the slant side length
- Every area formula traces back to the triangle formula: (1/2) x base x height
- For a general quadrilateral, draw one diagonal and measure perpendicular distances from the other two vertices to that diagonal
- Among triangles with the same base between parallel lines, all have equal area but the one with the **shortest perimeter** is found using the reflection trick
- Rectangle to equal-area triangle: keep the same base, use **double** the height
