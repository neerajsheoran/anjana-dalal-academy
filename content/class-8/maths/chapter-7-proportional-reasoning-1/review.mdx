## Key Concepts

- Proportionality means two quantities change by the **same factor** (multiplicative change)
- Same difference (additive change) does NOT guarantee proportionality
- A **ratio** a : b compares two quantities through division
- The numbers a and b are the **terms** of the ratio
- A ratio is in **simplest form** when both terms are divided by their **HCF**
- Two ratios are **proportional** if their simplest forms match: a : b :: c : d
- **Cross multiplication** test: a : b :: c : d if and only if **ad = bc**
- The **Rule of Three (Trairasika)**: if a : b :: c : d, then d = (b x c) / a
- The **unitary method**: find the value for 1 unit first, then multiply to the target quantity
- Adding or subtracting the same number to both ratio terms generally **changes** the ratio
- Multiplying or dividing both terms by the same number **preserves** the ratio
- Ratios help compare quantities with a uniform base
- Aryabhata (499 CE) formalised the Rule of Three with terms: Pramana, Phala, Ichchha

## Important Definitions

| Term | Meaning |
|------|---------|
| Ratio | Comparison of two quantities by division (a : b) |
| Simplest form | Ratio where both terms are divided by their HCF |
| Proportion | Two equal ratios (a : b :: c : d means a/b = c/d) |
| Cross multiplication | If a : b :: c : d, then ad = bc |
| Rule of Three (Trairasika) | Method to find the 4th unknown when three quantities and their proportion are known |
| Unitary method | Finding the value per single unit, then scaling up |

## Remember These

- Proportionality needs the same **factor** (multiply/divide), not the same **difference** (add/subtract)
- Ages do NOT stay proportional over time because they grow by addition, not multiplication
- Cross multiplication is the quickest way to verify if two ratios are proportional
- The unitary method and the Rule of Three are equivalent approaches -- use whichever feels more natural
