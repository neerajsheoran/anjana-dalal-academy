## Key Concepts

- A **number system** is a standardised sequence of symbols used for counting
- The written symbols in a number system are called **numerals**
- Early humans counted using physical objects (pebbles), body parts, and tally marks
- The **Lebombo bone** (~44,000 years old) is one of the oldest mathematical artefacts
- The **Roman system** uses landmark numbers I(1), V(5), X(10), L(50), C(100), D(500), M(1000) -- but has no consistent pattern, making arithmetic hard
- The **Egyptian system** was the first to use **powers of 10** as landmarks (base-10)
- A **base-n system** has landmarks at 1, n, n², n³, n⁴, ...
- The **Mesopotamian system** (base-60) introduced **place value** -- the position of a symbol determines its value
- The **Mayan system** (roughly base-20) independently invented place value and a symbol for zero
- The **Hindu (Indian) number system** combines base-10, place value, ten symbols (0-9), and zero as a full number
- India's system spread to the Arab world (~800 CE) and then to Europe (~1100 CE)
- **Aryabhata** (499 CE) first used the Indian system for full scientific computations
- **Brahmagupta** (628 CE) formally defined arithmetic of zero and negative numbers
- The number system the world uses today was created in **India** about 2000 years ago

## Important Definitions

| Term | Meaning |
|------|---------|
| Number system | A standardised sequence of symbols arranged in a fixed order for counting |
| Numerals | The written symbols used in a number system |
| Landmark numbers | Special reference points within a system (e.g., I, V, X in Roman) |
| Base | The number whose powers serve as landmarks (our system uses base 10) |
| Place value | The position of a digit determines which power of the base it represents |
| Zero | Both a placeholder and a genuine number with its own arithmetic properties |

## Remember These

- The Roman system made arithmetic extremely difficult -- multiplication and division required an abacus
- A **place value system** eliminates the need for infinitely many symbols -- position does the work
- **Zero** was India's breakthrough: not just a gap-filler but a real number where 0 + n = n and 0 x n = 0
- The evolution of number systems followed five key ideas: grouping, landmarks, base (powers), place value, and zero
