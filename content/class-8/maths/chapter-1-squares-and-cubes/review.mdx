## Key Concepts

- A **square number** is a number multiplied by itself: n² = n x n
- A **cube number** is a number multiplied by itself three times: n³ = n x n x n
- Numbers like 1, 4, 9, 16, 25, 36... are **perfect squares**
- Numbers like 1, 8, 27, 64, 125... are **perfect cubes**
- Perfect squares can only end in **0, 1, 4, 5, 6, or 9** -- never 2, 3, 7, or 8
- Perfect squares always have an **even** number of trailing zeros
- The square of an even number is even; the square of an odd number is odd
- The sum of the first n odd numbers equals **n²** (e.g., 1 + 3 + 5 + 7 = 4² = 16)
- Two consecutive **triangular numbers** add up to a perfect square
- The **square root** (√) reverses squaring; the **cube root** (∛) reverses cubing
- Every perfect square has two integer square roots: one positive and one negative
- A number is a perfect square if every prime factor appears an **even** number of times
- A number is a perfect cube if every prime factor appears a **multiple of 3** times
- **Prime factorisation** is the most reliable method for finding square and cube roots
- Cubes can end in **any digit** (0-9), unlike squares
- Cubing a negative number gives a **negative** result; squaring always gives positive
- **1729** is the Hardy-Ramanujan number: smallest number expressible as the sum of two cubes in two ways

## Important Definitions

| Term | Meaning |
|------|---------|
| Perfect square | A number that equals some whole number multiplied by itself (e.g., 36 = 6²) |
| Perfect cube | A number that equals some whole number multiplied by itself three times (e.g., 27 = 3³) |
| Square root (√) | The number which, when squared, gives the original number |
| Cube root (∛) | The number which, when cubed, gives the original number |
| Triangular number | Numbers formed by summing consecutive naturals: 1, 3, 6, 10, 15, 21... |
| Hardy-Ramanujan number | 1729 -- expressible as 1³ + 12³ and 9³ + 10³ |

## Remember These

- A number ending in 2, 3, 7, or 8 is **never** a perfect square -- but ending in 0, 1, 4, 5, 6, or 9 does not guarantee it is one
- To find √ by prime factorisation: pair up all factors -- take one from each pair
- To find ∛ by prime factorisation: group factors into triplets -- take one from each triplet
- The nth odd number is **2n - 1**, so the next square after n² is n² + (2n + 1) = (n+1)²
- For successive differences of cubes, the **third level** always gives a constant value of **6**
