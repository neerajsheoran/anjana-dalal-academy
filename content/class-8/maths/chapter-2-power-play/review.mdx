## Key Concepts

- **Exponential notation:** n^a means n multiplied by itself a times; n is the **base**, a is the **exponent**
- **Law 1 -- Same base, multiply:** n^a x n^b = n^(a+b)
- **Law 2 -- Power of a power:** (n^a)^b = n^(a x b)
- **Law 3 -- Same exponent, different bases:** m^a x n^a = (m x n)^a
- **Law 4 -- Same base, divide:** n^a / n^b = n^(a-b)
- **Zero exponent:** n⁰ = 1 for any non-zero n
- **Negative exponent:** n^(-a) = 1/n^a -- it means "take the reciprocal"
- All four laws work for positive, negative, and zero exponents
- **Scientific notation** writes numbers as x x 10^y where 1 ≤ x < 10
- Scientific notation makes it easy to compare very large or very small numbers
- Changing the exponent by 1 in scientific notation means a **10x** change in value
- **Exponential growth** (multiplying by a fixed factor) eventually dwarfs **linear growth** (adding a fixed amount)
- Powers of 10 appear throughout nature: from 10⁰ (rare species) to 10²³ (stars in the universe)
- Prime factorisation can be written compactly using exponents (e.g., 48600 = 2³ x 3⁵ x 5²)

## Important Definitions

| Term | Meaning |
|------|---------|
| Base | The number being multiplied repeatedly (e.g., 4 in 4³) |
| Exponent (power) | How many times the base is multiplied by itself (e.g., 3 in 4³) |
| Exponential form | A number written using base and exponent (e.g., 64 = 4³) |
| Scientific notation | Writing a number as x x 10^y where 1 ≤ x < 10 |
| Linear growth | Adding the same fixed amount at each step |
| Exponential growth | Multiplying by the same factor at each step |

## Remember These

- n⁰ = 1 (not 0!) for any non-zero n
- A negative exponent gives a **reciprocal**, not a negative number: 10^(-2) = 1/100, not -100
- In scientific notation, the coefficient must be between 1 and 10 (e.g., 7.2 x 10³, not 72 x 10²)
- Exponential growth starts slow but overtakes linear growth dramatically -- doubling for 30 days turns ₹1 into over ₹107 crore
