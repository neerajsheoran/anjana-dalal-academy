## Key Concepts

- The **distributive property**: a(b + c) = ab + ac -- break multiplication into smaller pieces
- It works from both sides: (a + b)c = ac + bc
- **General expansion:** (a + m)(b + n) = ab + mb + an + mn -- every term in the first bracket multiplies every term in the second
- If you know a x b, then a x (b+1) = ab + a, and (a+1)(b+1) = ab + a + b + 1
- **Identity 1A -- Square of a sum:** (a + b)² = a² + 2ab + b²
- **Identity 1B -- Square of a difference:** (a - b)² = a² - 2ab + b²
- **Identity 2 -- Difference of squares:** (a + b)(a - b) = a² - b²
- **Identity 3 -- Cube of a sum:** (a + b)³ = a³ + 3a²b + 3ab² + b³
- Multiplying by 11: add each pair of neighbouring digits (from right to left)
- Multiplying by 99: number x 100 - number
- Multiplying by 101: number x 100 + number (two-digit numbers just repeat!)
- **Like terms** have identical variable parts and can be combined; unlike terms cannot
- To expand products: multiply each term in one expression by every term in the other, then combine like terms
- Pattern: n(n + 2) = (n + 1)² - 1 (product of neighbours)
- Pattern: (a + b)² + (a - b)² = 2(a² + b²)

## Important Definitions

| Term | Meaning |
|------|---------|
| Distributive property | a(b + c) = ab + ac -- multiplication distributes over addition |
| Identity | An equation that holds true for all values of the variables |
| Like terms | Terms with identical variable parts (e.g., 4x²y and 9x²y) |
| Expansion | Writing a product as a sum by multiplying out all terms |

## Key Formulas

| Formula | Example |
|---------|---------|
| (a + b)² = a² + 2ab + b² | 72² = (70+2)² = 4900 + 280 + 4 = 5184 |
| (a - b)² = a² - 2ab + b² | 97² = (100-3)² = 10000 - 600 + 9 = 9409 |
| (a + b)(a - b) = a² - b² | 47 x 53 = (50-3)(50+3) = 2500 - 9 = 2491 |

## Remember These

- The difference of squares identity is a powerful shortcut: when two numbers are equally spaced from a round number, their product = (round number)² - (gap)²
- (a + b)² is NOT a² + b² -- the **2ab** middle term is the most commonly forgotten part
- (a - b)² always gives a **positive** result because it equals a² - 2ab + b²
- Brahmagupta called this technique **khanda-gunanam** (multiplication by segments) in 628 CE
