## Introduction

When we shop at a vegetable market, we often multiply prices mentally. If tomatoes cost Rs 40 per kg, buying 3 kg means paying Rs 120. But what if we need to calculate 40 x 97 in our head? Algebra gives us a powerful shortcut through a property called **distributivity** -- the bridge between multiplication and addition. This chapter reveals how this single idea unlocks fast calculations, elegant identities, and deep patterns in numbers.

---

## 6.1 Some Properties of Multiplication

### The Distributive Property

Consider any three numbers a, b, and c. The distributive property states:

**a(b + c) = ab + ac**

This is the **distributive property of multiplication over addition**.

**Think of it this way:** Imagine laying out tiles in a courtyard. You have a rows and (b + c) columns of tiles. Instead of counting all tiles at once, you can split the courtyard into two sections -- one with a rows and b columns (giving ab tiles), and another with a rows and c columns (giving ac tiles). The total number of tiles is ab + ac.

The property works from both sides:
- **(a + b)c = ac + bc**

> **Key idea:** Distributivity allows us to break apart a multiplication into smaller, friendlier pieces. This forms the backbone of all algebraic expansion.

---

### How Products Change

**Scenario:** Suppose we know that 19 x 32 = 608. Can we quickly find nearby products?

**Situation 1: Increase one number by 1**

a(b + 1) = ab + a

The product grows by **a** (the unchanged number). So 19 x 33 = 19 x 32 + 19 = 608 + 19 = 627.

**Situation 2: Increase both numbers by 1**

(a + 1)(b + 1) = ab + a + b + 1

The product grows by **a + b + 1**. So 20 x 33 = 608 + 19 + 32 + 1 = 660.

**Situation 3: One goes up by 1, the other drops by 1**

(a + 1)(b - 1) = ab + b - a - 1

The change is b - a - 1 (which could be positive or negative depending on which number is bigger).

---

### The General Expansion

For any numbers a, m, b, n:

**Identity 1: (a + m)(b + n) = ab + mb + an + mn**

Every term from the first bracket gets multiplied by every term from the second bracket.

**Example:** (17 + 3)(28 - 4) = 17 x 28 + 3 x 28 + 17 x (-4) + 3 x (-4) = 476 + 84 - 68 - 12 = 480

This rule holds for all integers, including negatives.

---

### Clever Multiplication Shortcuts

#### Multiplying by 11

Any number multiplied by 11 is the same as multiplying by (10 + 1), which means: number x 10 + number itself.

**Shortcut for multiplying by 11:**
1. Write down the last digit unchanged
2. Moving leftward, add each pair of neighbouring digits
3. Write the first digit unchanged (plus any carry)

**Example:** 5263 x 11
- Last digit: 3
- 6 + 3 = 9
- 2 + 6 = 8
- 5 + 2 = 7
- First digit: 5

Result: **57,893**

#### Multiplying by 101

Any number x 101 = number x 100 + number

For a two-digit number like 47: 47 x 101 = 4700 + 47 = 4747 (the digits simply repeat!)

#### Multiplying by 99 or 999

- number x 99 = number x 100 - number
- number x 999 = number x 1000 - number

**Example:** 43 x 99 = 4300 - 43 = 4257

> **Key idea:** These rapid calculation methods have deep roots in Indian mathematical tradition. **Brahmagupta** (628 CE) described this approach as **ista-gunana** (multiplication by chosen parts). **Sridharacharya** (750 CE) and **Bhaskaracharya** (1150 CE) further refined these techniques for merchants and astronomers.

## 6.2 Special Cases: Important Identities

### Identity 1A: Square of a Sum

**(a + b)² = a² + 2ab + b²**

**Geometric reasoning:** Picture a square floor tile with side length (a + b). Partition it into four regions:

![Square of side (a+b) divided into four regions: a-squared, b-squared, and two rectangles of area ab, proving the identity](square-of-sum-visual-proof.png)

- One square of side a (area a²)
- One square of side b (area b²)
- Two rectangles, each a by b (total area 2ab)

Altogether: a² + 2ab + b²

**Example:** Calculate 72²
- 72² = (70 + 2)² = 70² + 2(70)(2) + 2² = 4900 + 280 + 4 = **5184**

**Example:** Calculate 103²
- 103² = (100 + 3)² = 10000 + 600 + 9 = **10,609**

**Algebraic example:** Expand (4p + 7)²
- = (4p)² + 2(4p)(7) + 7² = 16p² + 56p + 49

---

### Identity 1B: Square of a Difference

**(a - b)² = a² - 2ab + b²**

We can obtain this by substituting (-b) for b in Identity 1A:
- (a + (-b))² = a² + 2a(-b) + (-b)² = a² - 2ab + b²

**Geometrically:** Start with a square of side a. Remove two strips of width b (one from the right edge, one from the bottom). But the small corner square of side b was removed twice, so add it back once. The remaining area is a² - 2ab + b².

**Example:** Calculate 97²
- 97² = (100 - 3)² = 10000 - 600 + 9 = **9409**

**Example:** Calculate 48²
- 48² = (50 - 2)² = 2500 - 200 + 4 = **2304**

**Algebraic example:** Expand (5m - 4n)²
- = 25m² - 40mn + 16n²

---

### Identity 2: Difference of Squares

**(a + b)(a - b) = a² - b²**

**Derivation using distributivity:**
- (a + b)(a - b) = a² - ab + ab - b² = a² - b²

**Example:** 47 x 53 = (50 - 3)(50 + 3) = 50² - 3² = 2500 - 9 = **2491**

**Example:** 101 x 99 = (100 + 1)(100 - 1) = 10000 - 1 = **9999**

> **Key idea:** Whenever two numbers sit at equal distances above and below a round number, their product equals the square of that round number minus the square of the gap.

---

### Identity 3: Cube of a Sum

**(a + b)³ = a³ + 3a²b + 3ab² + b³**

We can derive this by multiplying (a + b) with (a + b)²:
- (a + b)(a² + 2ab + b²)
- = a³ + 2a²b + ab² + a²b + 2ab² + b³
- = a³ + 3a²b + 3ab² + b³

---

### Discovering Patterns

**Pattern 1:** The product of neighbours

- 2 x 4 = 8 = 3² - 1
- 4 x 6 = 24 = 5² - 1
- 7 x 9 = 63 = 8² - 1

In general: n(n + 2) = (n + 1)² - 1. This is a direct consequence of (a - b)(a + b) = a² - b² with a = n + 1, b = 1.

**Pattern 2:** Adding two related squares

- (a + b)² + (a - b)² = 2(a² + b²)

This tells us that the sum of the squares of two numbers equally spaced around a middle value always equals twice the sum of the square of the middle and the square of the spacing.

## Working with Algebraic Expressions

### Like Terms

**Like terms** share identical variable parts. Only like terms can be added or subtracted.

- 4x²y and 9x²y are like terms (their sum is 13x²y)
- 4x² and 9xy are NOT like terms (they cannot be combined)

### Expanding Products of Expressions

To expand a product, multiply every term in the first expression by every term in the second, then gather like terms.

**Example:** Expand (a + b)(a² + 2ab + b²)
- = a³ + 2a²b + ab² + a²b + 2ab² + b³
- = a³ + 3a²b + 3ab² + b³ (after combining like terms)

---

### Historical Spotlight

The **distributive property** was understood by thinkers across many ancient cultures -- Egyptian scribes, Mesopotamian accountants, Greek geometers, and Chinese mathematicians all used versions of it. **Euclid** expressed it through geometric propositions, while **Aryabhata** applied it algebraically.

The first **clear algebraic statement** of distributivity came from **Brahmagupta** in his Brahmasphuasiddhanta (628 CE, Verse 12.55). He named it **khanda-gunanam** (multiplication by segments): "Split the multiplier into two or more pieces that add up to it; multiply the multiplicand by each piece separately and combine the results."

## Summary

- The **distributive property**: a(b + c) = ab + ac, links multiplication with addition.
- **General expansion:** (a + m)(b + n) = ab + mb + an + mn
- **Identity 1A:** (a + b)² = a² + 2ab + b² (square of a sum)
- **Identity 1B:** (a - b)² = a² - 2ab + b² (square of a difference)
- **Identity 2:** (a + b)(a - b) = a² - b² (difference of squares)
- These identities power fast mental arithmetic, simplify algebraic expressions, and reveal hidden patterns.
- **Like terms** (matching variable parts) can be combined; unlike terms cannot.
- Expand products by multiplying each term in one expression by every term in the other, then combine like terms.
