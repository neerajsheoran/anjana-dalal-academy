## Key Concepts

- **Data** is a collection of numbers, facts, or observations gathered for a purpose
- Data must be **collected** (e.g., through a survey) and then **organised** to be useful
- **Tally marks** group counts in fives (four vertical lines + one diagonal slash) for quick recording
- A **frequency table** lists categories alongside the number of times each appears (its **frequency**)
- Always verify: sum of all frequencies must equal the total data points
- A **pictograph** uses symbols/pictures to represent data; each symbol stands for a fixed number stated in the **key**
- To read a pictograph: count symbols and multiply by the key value
- Choose a pictograph scale that divides evenly into all data values
- A **bar graph** uses rectangular bars of equal width; bar height represents the exact value
- Parts of a bar graph: **title**, **X-axis** (categories), **Y-axis** (values), **scale**, **bars**, **labels**
- Bar graphs are more precise than pictographs -- you can read exact values from the axis
- **Horizontal bar graphs** are useful when category names are long
- Use pictographs for small, simple data; use bar graphs for larger or more varied data
- Drawing conclusions from data means looking for **patterns**, **comparing groups**, and asking **why**
- Compare using **percentages**, not just raw numbers, to get accurate insights
- Good data analysis asks: Why? Is it consistent? Could there be another explanation?

## Important Definitions

| Term | Meaning |
|------|---------|
| **Data** | Facts, numbers, or observations collected for a purpose |
| **Survey** | Collecting data by asking questions to a group |
| **Tally marks** | Counting method using groups of five strokes |
| **Frequency** | How many times a value or category occurs |
| **Frequency table** | A table listing categories with their frequencies |
| **Pictograph** | Graph using picture symbols to represent data |
| **Key (Scale)** | States how many items each pictograph symbol represents |
| **Bar graph** | Graph using rectangular bars; height shows the value |
| **X-axis** | Horizontal axis, usually showing categories |
| **Y-axis** | Vertical axis, usually showing numerical values |

## Remember These

- The sum of all frequencies must match the total number of data points -- always cross-check
- In a pictograph, choose a scale that divides evenly into ALL data values
- Bar graphs need equal bar widths and equal gaps between bars
- Raw numbers can be misleading -- always consider **percentages** when comparing groups of different sizes
- Data tells a story, but always ask if there is more to the story than what appears on the surface
