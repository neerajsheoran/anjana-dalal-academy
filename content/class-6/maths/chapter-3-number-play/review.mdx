## Key Concepts

- Numbers serve three roles: **naming** (pin codes, jersey numbers), **counting** (how many), and **measuring** (position, size)
- A **palindromic number** reads the same forwards and backwards (e.g., 12921, 252)
- **Reverse-and-Add method**: reverse digits, add to original, repeat until you get a palindrome
- The **1089 trick**: take any 3-digit number (first and last digits differ by 2+), reverse, subtract, then reverse the result and add -- always gives **1089**
- **Kaprekar's Constant = 6174**: arrange any 4-digit number's digits descending minus ascending, repeat -- always reaches 6174 within 7 steps
- **Divisibility rule for 2**: last digit is even (0, 2, 4, 6, 8)
- **Divisibility rule for 3**: digit sum divisible by 3
- **Divisibility rule for 4**: last two digits divisible by 4
- **Divisibility rule for 5**: last digit is 0 or 5
- **Divisibility rule for 6**: divisible by both 2 and 3
- **Divisibility rule for 8**: last three digits divisible by 8
- **Divisibility rule for 9**: digit sum divisible by 9
- **Divisibility rule for 10**: last digit is 0
- **Divisibility rule for 11**: alternating sum of digits (from right) is 0 or divisible by 11
- **Rounding**: look at the digit to the right of rounding place; 5 or more = round up, less than 5 = round down
- **Estimation strategies**: round both numbers, front-end estimation, or use compatible numbers

## Important Definitions

| Term | Meaning |
|------|---------|
| **Palindromic number** | Reads the same forwards and backwards (e.g., 14641) |
| **1089 trick** | 3-digit reversal-subtraction-addition always yields 1089 |
| **Kaprekar's Constant** | 6174 -- fixed point of the Kaprekar process for 4-digit numbers |
| **Divisibility rule** | A shortcut to check if one number divides another without dividing |
| **Digit sum** | Sum of all digits of a number |
| **Estimation** | Finding a value close enough to the exact answer for practical use |
| **Rounding** | Replacing a number with a nearby "rounder" number |
| **Nominal number** | A number used as a label, not for counting or measuring |

## Remember These

- D. R. Kaprekar was a school teacher from Devlali, Maharashtra -- great maths can come from anyone
- For divisibility by 6, you must check BOTH rules (divisible by 2 AND by 3)
- The 1089 trick only works when the first and last digits differ by at least 2
- Estimation is not guessing -- it is a deliberate strategy using rounding or compatible numbers
- Know when exact answers matter (bank transactions) vs. when estimates suffice (shopping)
