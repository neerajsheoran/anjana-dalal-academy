## Key Concepts

- A **fraction** = numerator / denominator; parts must be **equal**
- **Numerator** (top) = how many parts taken; **Denominator** (bottom) = total equal parts
- **Proper fraction**: numerator < denominator (value between 0 and 1)
- **Improper fraction**: numerator ≥ denominator (value is 1 or more)
- **Mixed number** = whole number + proper fraction (e.g., 3 2/5)
- Improper to mixed: divide numerator by denominator; quotient = whole part, remainder = new numerator
- Mixed to improper: (whole x denominator) + numerator over same denominator
- **Equivalent fractions**: multiply or divide both numerator and denominator by the same number
- Test equivalence using **cross multiplication**: a/b = c/d if a x d = b x c
- **Simplest form**: divide both by their **HCF** until HCF = 1
- **Comparing fractions** (same denominator): larger numerator = larger fraction
- **Comparing fractions** (same numerator): smaller denominator = larger fraction
- **Comparing fractions** (both different): use cross multiplication or find **LCM** of denominators
- **Adding/subtracting** with same denominator: add/subtract numerators, keep denominator
- **Adding/subtracting** with different denominators: find LCM, convert, then add/subtract
- **Multiplying fractions**: (a/b) x (c/d) = (a x c) / (b x d); cancel common factors first
- "**Of**" means multiply: 3/4 of 32 = 3/4 x 32 = 24
- A **unit fraction** has numerator 1 (e.g., 1/2, 1/3, 1/7)

## Important Definitions

| Term | Meaning |
|------|---------|
| **Fraction** | A part of a whole: numerator over denominator |
| **Numerator** | Top number; counts parts being considered |
| **Denominator** | Bottom number; total equal parts in the whole |
| **Proper fraction** | Numerator < denominator (between 0 and 1) |
| **Improper fraction** | Numerator ≥ denominator (1 or more) |
| **Mixed number** | Whole number + proper fraction |
| **Equivalent fractions** | Different-looking fractions representing the same value |
| **Simplest form** | HCF of numerator and denominator is 1 |
| **Unit fraction** | A fraction with numerator 1 |

## Remember These

- Parts MUST be equal for a fraction to be valid -- unequal pieces cannot be written as fractions
- When comparing fractions with the same numerator, the **smaller** denominator gives the **larger** fraction (bigger pieces)
- When adding mixed numbers, handle whole parts and fraction parts **separately**
- Always **simplify** your final answer
- Cancel common factors **before** multiplying fractions to keep numbers small
