## Key Concepts

- A **pattern** is any arrangement that follows a predictable rule; recognising the rule lets you **predict** what comes next
- **Natural numbers** (1, 2, 3, ...): add 1 each time
- **Even numbers** (2, 4, 6, ...): formula = **2n**; divisible by 2 with no remainder
- **Odd numbers** (1, 3, 5, ...): formula = **2n - 1**; leave remainder 1 when divided by 2
- **Triangular numbers** (1, 3, 6, 10, 15, ...): formula = **n(n+1) / 2**; formed by adding consecutive natural numbers
- **Square numbers** (1, 4, 9, 16, 25, ...): formula = **n**²; sum of first n odd numbers = n²
- **Cube numbers** (1, 8, 27, 64, ...): formula = **n**³; sum of first n cubes = (nth triangular number)²
- **Powers of 2** (1, 2, 4, 8, 16, ...): each term is double the previous; shows exponential growth
- **Virahanka numbers** (1, 1, 2, 3, 5, 8, 13, ...): each term = sum of the two previous terms; discovered by Indian scholar Virahanka (~700 CE)
- Two consecutive **triangular numbers** add up to a **square number** (e.g., 3 + 6 = 9 = 3²)
- **Figurate numbers** are numbers visualised as geometric shapes (triangles, squares, cubes)
- A **gnomon** is the L-shaped layer added to build the next square number; each gnomon has an odd number of dots
- **Fractals** are shapes where a small part looks like the whole (e.g., cauliflower, coastlines)
- To find a sequence rule: check **differences**, check **ratios**, or connect terms to their **position numbers**
- The **palindrome pattern**: 1×1 = 1, 11×11 = 121, 111×111 = 12321, etc.
- Digits of every multiple of 9 add up to 9

## Important Definitions

| Term | Meaning |
|------|---------|
| **Pattern** | An arrangement that follows a predictable rule |
| **Sequence** | An ordered list of numbers following a rule |
| **Term** | Each individual number in a sequence |
| **Triangular number** | n(n+1) / 2; dots forming a triangle |
| **Square number** | n²; dots forming a square |
| **Cube number** | n³; a number multiplied by itself three times |
| **Virahanka numbers** | Each term is the sum of the previous two (1, 1, 2, 3, 5, 8, ...) |
| **Gnomon** | The L-shaped layer added to build the next square |
| **Fractal** | A shape whose parts resemble the whole at every zoom level |

## Remember These

- Sum of first n odd numbers = **n²** (e.g., 1+3+5+7 = 16 = 4²)
- nth triangular number = **n(n+1)/2** (e.g., 100th = 5050)
- Sum of first n cubes = **(sum of first n natural numbers)²**
- 1 is NOT a Virahanka number start -- the sequence begins 1, 1, 2, 3, 5, 8
- Virahanka discovered this sequence centuries before Fibonacci
