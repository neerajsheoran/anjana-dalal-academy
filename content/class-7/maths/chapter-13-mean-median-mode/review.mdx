## Key Concepts

- **Statistics** is the study of collecting, organising, analysing, interpreting, and presenting data
- A **statistical question** expects variable answers and requires data collection (unlike fixed-answer questions)
- **Mean (arithmetic mean)** = total of all values / count of values -- the "average"
- The mean represents what each person would get if everything were **distributed equally**
- A **dot plot** shows each data value as a dot on a number line -- good for spotting clusters and spread
- **Range** = maximum value - minimum value (shows how widely data is spread)
- An **outlier** is an extreme value far from the rest; it can **drag the mean** away from the typical value
- The **median** is the middle value when data is sorted from smallest to largest
  - Odd count: the single middle value
  - Even count: average of the two middle values
- The median is **resistant to outliers** -- it barely changes when extreme values are present
- Use **mean** when data has no extreme values; use **median** when outliers are present
- A **bar graph** uses rectangular bars (equal width, equal gaps) to display data; height = value
- A **double bar graph** places two data sets side by side for comparison
- Bar graph scales should always **start from 0** to avoid exaggerating differences

## Important Definitions

| Term | Meaning |
|------|---------|
| Statistics | The study of collecting, organising, analysing, and presenting data |
| Statistical question | A question requiring data collection with variable answers |
| Mean | Total of all values / count of values |
| Median | The middle value in a sorted data set |
| Outlier | A value far removed from the rest of the data |
| Range | Gap between the maximum and minimum values |
| Dot plot | Graph showing each data value as a dot on a number line |
| Bar graph | Graph using rectangular bars to compare data |
| Double bar graph | Bar graph with two data sets placed side by side |
| Scale | Unit size for marking values on a graph axis |

## Remember These

- The **mean is sensitive to outliers** -- one extreme value can make it misleading; the **median stays stable**
- For median with an **even count**, you must **average the two middle values**
- Bar graph scales must start at **0** -- a scale starting at a higher number exaggerates small differences
- Brahmagupta used *samarajju* for the mean concept; Mahaviracharya used *samkarana* meaning "levelling"
