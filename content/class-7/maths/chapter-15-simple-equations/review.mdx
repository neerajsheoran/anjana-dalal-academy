## Key Concepts

- An **equation** declares two expressions equal using the **= sign** (e.g., 3x + 1 = 76)
- Every equation has a **LHS** (left-hand side) and **RHS** (right-hand side)
- An **expression** has no equals sign; an **equation** does and can be solved
- The **solution** is the value of the variable that makes the equation true
- **Trial and error:** test different values until LHS = RHS (works but can be slow)
- **Balance principle:** doing the same operation to both sides keeps the equation true
- To **undo addition**, subtract from both sides; to **undo subtraction**, add to both sides
- To **undo multiplication**, divide both sides; to **undo division**, multiply both sides
- **Two-step equations:** first undo addition/subtraction, then undo multiplication/division
  - Example: 4x - 7 = 21 => 4x = 28 => x = 7
- When the **variable appears on both sides:** move all variable terms to one side, constants to the other
  - Example: 4x + 3 = 2x + 15 => 2x = 12 => x = 6
- **Word problems:** identify the unknown, write an equation, solve, then verify
- **Always check** by substituting the solution back into the original equation

## Important Definitions

| Term | Meaning |
|------|---------|
| Equation | A statement declaring two expressions equal using = |
| LHS / RHS | Left-hand side / Right-hand side of an equation |
| Solution | The value of the unknown that makes the equation true |
| Balance principle | Doing the same operation on both sides keeps the equation true |
| Trial and error | Testing values to find which one satisfies the equation |
| Variable (Unknown) | The letter whose value we need to find |
| Consecutive numbers | Numbers in order, like 17, 18, 19 |

## Remember These

- **Always verify your answer** by plugging it back into the **original** equation -- this catches sign errors
- In two-step equations, **undo addition/subtraction first**, then multiplication/division
- When the variable is on **both sides**, subtract the smaller variable term from both sides first
- The word "algebra" comes from Arabic "al-jabr"; Indian mathematicians **Brahmagupta** and **Aryabhata** independently developed equation-solving methods
