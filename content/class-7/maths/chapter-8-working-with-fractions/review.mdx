## Key Concepts

- **Whole number x fraction:** multiply the whole number with the numerator, keep the denominator: n x a/b = (n x a)/b
- **Fraction x whole number:** same rule: a/b x n = (a x n)/b
- **Fraction x fraction:** multiply tops together and bottoms together: a/b x c/d = (a x c)/(b x d)
- **Shortcut:** cancel common factors between numerators and denominators **before** multiplying
- For **mixed numbers**, convert to improper fractions first, then multiply
- Multiplying by a **proper fraction** (less than 1) makes the number **smaller**
- Multiplying by an **improper fraction** (greater than 1) makes the number **larger**
- **"Fraction of"** means multiplication: 3/4 of 80 = 3/4 x 80 = 60
- **Reciprocal** of a/b is b/a -- swap numerator and denominator; any number times its reciprocal = **1**
- **Division by a fraction** = multiplication by its reciprocal: a/b / c/d = a/b x d/c
- To divide a whole number by a fraction: multiply by the reciprocal (2 / 1/4 = 2 x 4 = 8)

## Important Definitions

| Term | Meaning |
|------|---------|
| Fraction | A number written as a/b (numerator/denominator) |
| Proper fraction | Numerator < denominator (value less than 1) |
| Improper fraction | Numerator >= denominator (value 1 or more) |
| Mixed number | Whole number + proper fraction (e.g., 1 2/3) |
| Reciprocal | Fraction flipped: a/b becomes b/a |
| Multiplying fractions | (a/b) x (c/d) = (ac)/(bd) |
| Dividing fractions | (a/b) / (c/d) = (a/b) x (d/c) |

## Remember These

- **Dividing by a fraction makes the answer bigger**, not smaller (e.g., 2 / 1/4 = 8)
- Always **convert mixed numbers to improper fractions** before multiplying or dividing
- **Cancel common factors first** to avoid working with large numbers
- The reciprocal of a whole number n is **1/n**, and the reciprocal of 1/n is **n**
