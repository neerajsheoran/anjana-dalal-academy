## Key Concepts

- An **arithmetic expression** is a combination of numbers and operations (+, -, x, /) that produces a single **value**
- **Terms** are parts of an expression separated by the **+** sign (rewrite subtraction as addition of negatives first)
- A product like 8 x 3 counts as a **single term** because it has no + sign within it
- **Brackets** indicate "do this part first" -- always evaluate inside brackets before anything else
- To evaluate: identify terms, compute each term individually, then add all terms together
- **Commutative property of addition:** changing the order of terms does not change the sum (a + b = b + a)
- **Associative property of addition:** changing the grouping does not change the sum
- **Distributive property:** a x (b + c) = a x b + a x c
- When a **minus sign** precedes brackets, removing the brackets **flips all signs** inside
- When a **plus sign** precedes brackets, signs inside remain **unchanged**
- The distributive property enables smart calculations: 98 x 15 = (100 - 2) x 15 = 1500 - 30 = 1470
- **Factoring out** common factors simplifies expressions: 7 x 6 + 3 x 6 = (7 + 3) x 6 = 60
- The **inverse** of a number has the opposite sign: inverse of 8 is -8

## Important Definitions

| Term | Meaning |
|------|---------|
| Arithmetic expression | A mathematical phrase combining numbers with operations |
| Value | The single number an expression equals when evaluated |
| Terms | Parts of an expression separated by the + sign |
| Brackets | Symbols ( ) marking which part must be evaluated first |
| Commutative property | Order of terms in addition does not matter |
| Associative property | Grouping of terms in addition does not matter |
| Distributive property | a x (b + c) = a x b + a x c |
| Inverse | A number with the opposite sign |

## Remember These

- **Multiplication and division** inside a term are done **before** adding terms together -- this is why order matters
- Minus before brackets **flips** every sign inside: -(a + b) = -a - b and -(a - b) = -a + b
- Plus before brackets changes **nothing**: +(a - b) = a - b
- Always verify your answer with estimation when working with large expressions
