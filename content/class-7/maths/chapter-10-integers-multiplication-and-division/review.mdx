## Key Concepts

- **Integers** include all positive numbers, negative numbers, and zero: ..., -3, -2, -1, 0, 1, 2, 3, ...
- The **additive inverse** of a is -a; adding a number and its additive inverse gives **0**
- **Sign rules for multiplication:**
  - Positive x Positive = **Positive**
  - Positive x Negative = **Negative**
  - Negative x Positive = **Negative**
  - Negative x Negative = **Positive**
- **Memory aid:** matching signs give **positive**; clashing signs give **negative**
- The **magnitude** of the product = product of individual magnitudes, regardless of signs
- The **same sign rules apply to division** (since division reverses multiplication)
- **Commutative property:** a x b = b x a
- **Associative property:** (a x b) x c = a x (b x c)
- **Distributive property:** a x (b + c) = a x b + a x c
- **Special cases:** a x 0 = 0; a x 1 = a; a x (-1) = -a (flips the sign)
- **Division by zero is undefined** -- no number multiplied by 0 produces a non-zero result
- Division is **not commutative**: 15 / 3 is not the same as 3 / 15
- **Brahmagupta** (628 CE) first wrote systematic rules for arithmetic with negatives and zero

## Important Definitions

| Term | Meaning |
|------|---------|
| Integer | Any positive number, negative number, or zero |
| Additive inverse | The number that cancels a given number: additive inverse of a is -a |
| Positive product | Result when matching signs are multiplied |
| Negative product | Result when clashing signs are multiplied |
| Commutative property | a x b = b x a |
| Associative property | (a x b) x c = a x (b x c) |
| Distributive property | a x (b + c) = a x b + a x c |
| Undefined | Division by zero has no meaningful result |

## Remember These

- **Negative x Negative = Positive** -- this is the rule students forget most often
- **Multiplying by -1** simply flips the sign of any integer
- **Division by zero is undefined** -- never write something like 5/0 = 0
- If you know one product (e.g., 245 x 312 = 76,440), you can instantly find products with negative versions by applying sign rules
