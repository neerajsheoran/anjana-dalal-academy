## Key Concepts

- A **letter-number (variable)** is a letter representing a number that can take different values
- An **algebraic expression** combines variables, numbers, and operations (e.g., 3n + 5)
- In algebra, multiplication is written compactly: 3 x n becomes **3n** (number always goes first)
- A **formula** is an algebraic expression describing a general relationship (e.g., Perimeter of square = 4s)
- **Like terms** share the same variable and can be combined: 8m + 2m = 10m
- **Unlike terms** have different variables and cannot be combined: 8x + 3y stays as is
- To combine like terms, use the **distributive property**: 8x + 3x = (8 + 3)x = 11x
- **Plus sign before brackets:** signs inside stay unchanged: +(4a - 2b) = 4a - 2b
- **Minus sign before brackets:** all signs inside flip: -(4a - 2b) = -4a + 2b
- **Distributive property with variables:** 3(p + q) = 3p + 3q
- To check if two expressions are equal, **substitute values** and compare results
- 4t and 4 + t are **not** the same expression; 8y - 5 and 8(y - 5) are **not** the same
- Rectangle perimeter: l + w + l + w simplifies to **2l + 2w**

## Important Definitions

| Term | Meaning |
|------|---------|
| Variable (Letter-number) | A letter representing a number that can change |
| Algebraic expression | A mathematical expression with variables, numbers, and operations |
| Formula | An algebraic expression for a general relationship |
| Like terms | Terms with the same variable (e.g., 8x and 3x) |
| Unlike terms | Terms with different variables (e.g., 8x and 3y) |
| Simplification | Merging like terms to write an expression more compactly |
| Distributive property | a(b + c) = ab + ac |

## Remember These

- **2g means 2 x g**, not the number 2 followed by g -- so if g = 5, 2g = 10 (not 25)
- If b = -3, then 8 - b = 8 - (-3) = **11**, not 5 -- watch signs with negatives
- Like terms combine; unlike terms **do not** -- never add 3x and 5y to get 8xy
- Always verify whether two expressions are truly equal by plugging in test values
