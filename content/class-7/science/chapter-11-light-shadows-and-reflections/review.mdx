## Key Concepts

- **Luminous objects** produce their own light (Sun, stars, bulbs, candles, fireflies)
- **Non-luminous objects** do not produce light; we see them because they **reflect** light from a luminous source
- The **Moon** is non-luminous -- it shines by reflecting sunlight
- Light travels in **straight lines** -- this property is called **rectilinear propagation of light**
- **Transparent** materials let light pass through completely (clear glass, water, air)
- **Translucent** materials let only some light through; objects appear blurry (frosted glass, oiled paper)
- **Opaque** materials block all light (brick wall, wooden door, iron sheet)
- A **shadow** forms when an opaque object blocks light -- three requirements: **light source**, **opaque object**, **screen**
- Shadow properties: always **dark** (no colour), size changes with object/source distance, shape changes with angle
- Moving the object **closer to the light** makes the shadow **bigger**; closer to the screen makes it **smaller**
- The **colour** of the object does **not** affect the shadow
- **Reflection** is the bouncing back of light from a shiny surface
- A **plane mirror** produces an image that is **same size**, **upright**, and **laterally inverted**
- The image appears the **same distance** behind the mirror as the object is in front
- A plane mirror image **cannot be captured on a screen** (virtual image)
- **Lateral inversion**: left and right are swapped in a mirror image
- **AMBULANCE** is written in reverse on vehicles so it reads correctly in a rear-view mirror
- A **pinhole camera** produces an **inverted** (upside down) image on a screen -- demonstrates straight-line travel of light
- A **periscope** uses two plane mirrors in a Z-shaped tube to see objects not in direct line of sight (used in submarines, military)
- A **kaleidoscope** uses three mirrors in a triangle to create symmetrical patterns

## Important Definitions

| Term | Meaning |
|------|---------|
| Luminous object | An object that produces and emits its own light |
| Non-luminous object | An object that does not produce its own light |
| Rectilinear propagation | The property of light travelling in straight lines |
| Transparent | A material that allows all light to pass through |
| Translucent | A material that allows only some light to pass through |
| Opaque | A material that blocks all light |
| Shadow | A dark region formed when an opaque object blocks light |
| Reflection | The bouncing back of light from a surface |
| Lateral inversion | The left-right reversal in a mirror image |
| Pinhole camera | A simple device using a tiny hole to form an inverted image on a screen |
| Periscope | A device using two mirrors to see objects around corners or over obstacles |

## Remember These

- Shadow has **no colour** -- it is simply a region of no light, regardless of the object's colour
- Plane mirror image: **same size, upright, laterally inverted, cannot be caught on screen**
- Pinhole camera image: **inverted, can be caught on screen, NOT laterally inverted**
- Light cannot bend around corners -- this is why shadows have sharp edges and why you cannot see around walls
- AMBULANCE is mirror-written so drivers can read it correctly in their **rear-view mirror**
