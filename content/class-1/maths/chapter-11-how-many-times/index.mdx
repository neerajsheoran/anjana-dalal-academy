## A Trip to the Village Mela

Sahil and his cousins are at a village mela (fair). There are rides, food stalls, and games everywhere! Let us use maths to count things at the mela.

---

## Counting in Groups (Repeated Addition)

Instead of counting things one by one, we can put them into **equal groups** and add them up. This is much faster!

### The Ferris Wheel

The ferris wheel has small cabins. Each cabin holds **2 children**. There are **5 cabins**.

2 + 2 + 2 + 2 + 2 = **10**

So, **5 times 2** is **10**. Ten children can ride the ferris wheel at once!

### The Camel Ride

Three camels are waiting to give rides. Each camel carries **4 children**.

4 + 4 + 4 = **12**

So, **3 times 4** is **12**. Twelve children can enjoy the camel ride!

### The Merry-Go-Round

The merry-go-round has **6 wooden horses**. Each horse seats **2 children**.

2 + 2 + 2 + 2 + 2 + 2 = **12**

So, **6 times 2** is **12**.

---

## Understanding Times

When we keep adding the **same number again and again**, we call it adding that number a certain number of **times**.

- 3 + 3 + 3 = adding 3, **three times** = **9**
- 5 + 5 = adding 5, **two times** = **10**
- 4 + 4 + 4 + 4 = adding 4, **four times** = **16**

This is called **repeated addition** — the same number being added over and over.

## Samosas for Everyone!

After the rides, the children are hungry! Each plate at the samosa stall holds **2 samosas**. They ordered **7 plates**.

2 + 2 + 2 + 2 + 2 + 2 + 2 = **14**

**7 times 2 is 14.** They got 14 samosas in all!

## Travelling in an Auto-Rickshaw

An auto-rickshaw can carry **3 passengers** at a time. If **4 auto-rickshaws** leave the mela together, how many passengers are travelling?

3 + 3 + 3 + 3 = **12**

**4 times 3 is 12.** Twelve passengers are on their way home!

## Bangles at the Stall

Meera stops at a bangle stall. The shopkeeper sells bangles in sets. Each set has **5 bangles**. Meera picks **3 sets**.

5 + 5 + 5 = **15**

**3 times 5 is 15.** Meera has 15 bangles now!

## Counting Things in Groups Around Us

Look around — so many things naturally come in equal groups!

| Thing | How Many in Each Group | How Many Groups | Total |
|-------|----------------------|----------------|-------|
| Wheels on a scooter | 2 | 4 scooters | 2 + 2 + 2 + 2 = **8 wheels** |
| Legs on a stool | 3 | 3 stools | 3 + 3 + 3 = **9 legs** |
| Corners of a square | 4 | 2 squares | 4 + 4 = **8 corners** |
| Fingers on one hand | 5 | 2 hands | 5 + 5 = **10 fingers** |
| Wheels on an auto | 3 | 5 autos | 3 + 3 + 3 + 3 + 3 = **15 wheels** |

> **Activity:** Count the legs on all the chairs in your room. Each chair has 4 legs. If there are 3 chairs, how many legs?
> 4 + 4 + 4 = **12 legs**

## Key Words to Remember

| Word | Meaning |
|------|---------|
| **Repeated addition** | Adding the same number again and again |
| **Times** | How many groups of the same number we add (e.g., 4 times 3 means 3 + 3 + 3 + 3) |
| **Group** | A set of things that belong together |
| **Total** | The final answer we get after adding all the groups |
| **Each** | Every single one (e.g., each plate has 2 samosas) |
