## Key Concepts

- **Measures of central tendency**: mean, median, and mode -- they capture the "typical" value in data
- **Class mark** (midpoint) = (Upper limit + Lower limit) / 2
- **Mean** -- three methods, all give the **same answer**:
  - **Direct**: Mean = Sum(f_i x_i) / Sum(f_i)
  - **Assumed mean**: Mean = a + Sum(f_i d_i) / Sum(f_i), where d_i = x_i - a
  - **Step-deviation**: Mean = a + [Sum(f_i u_i) / Sum(f_i)] x h, where u_i = (x_i - a)/h
- **Mode** = l + [(f1 - f0) / (2f1 - f0 - f2)] x h
  - l = lower boundary of modal class, f1 = modal class frequency, f0 = frequency before, f2 = frequency after, h = class width
- **Modal class** = class with the **highest frequency**
- **Median** = l + [(n/2 - cf) / f] x h
  - l = lower boundary of median class, cf = cumulative frequency before median class, f = frequency of median class
- **Median class**: the class whose cumulative frequency **first exceeds** n/2
- **Cumulative frequency**: running total of frequencies
- **Ogive**: graph of cumulative frequency -- "less than" type rises, "more than" type falls
- Median = x-coordinate where the two ogives **intersect**
- Empirical relationship: **3 Median = Mode + 2 Mean** (approximate)

## Important Definitions

| Term | Meaning |
|------|---------|
| **Mean** | Arithmetic average of all values |
| **Median** | Middle value that splits data into two equal halves |
| **Mode** | Most frequently occurring value |
| **Class mark** | Midpoint of a class interval |
| **Ogive** | Cumulative frequency curve |
| **Modal class** | Class interval with the highest frequency |

## Remember These

- If class intervals are **not continuous** (e.g., 1-10, 11-20), adjust by 0.5 to make them continuous before applying formulas
- All three mean methods give **identical results** -- choose based on what the question asks or which simplifies computation
- For median: build the cumulative frequency column **carefully** -- errors here cascade through the answer
- Mode is best when you need the **most popular** value (shoe size, salary bracket)
- The empirical formula 3 Median = Mode + 2 Mean is an **approximation**, not exact -- use it only when asked
