## Key Concepts

- Standard form: **ax^2 + bx + c = 0** where a, b, c are real and **a is not zero**
- A quadratic equation has **at most two roots**
- **Factorisation method**: split the middle term -- find two numbers with product = ac and sum = b
- **Completing the square**: transform to (x + p)^2 = q form, then take square roots
- **Quadratic formula**: x = **(-b +/- root(b^2 - 4ac)) / 2a**
- The **discriminant** D = **b^2 - 4ac** determines the nature of roots:
  - D > 0: two **distinct** real roots
  - D = 0: two **equal** real roots (x = -b/2a)
  - D < 0: **no** real roots
- Always simplify and rearrange an equation to standard form before deciding if it is quadratic
- For equal roots, set **D = 0** and solve for the unknown parameter (k)
- Reject negative roots when the variable represents a physical quantity (length, age, speed)
- Word problems: translate area, speed, age, and number problems into quadratic form

## Important Definitions

| Term | Meaning |
|------|---------|
| **Quadratic equation** | Polynomial equation of degree 2 in standard form ax^2 + bx + c = 0 |
| **Root / Solution** | Value of x that satisfies the equation |
| **Discriminant (D)** | b^2 - 4ac; determines nature of roots |
| **Completing the square** | Rewriting ax^2 + bx + c as a perfect square expression |

## Remember These

- The quadratic formula works for **every** quadratic equation -- use it when factorisation is not obvious
- **D = 0** questions ("find k for equal roots") are very common in board exams
- When D = 0, both roots are **-b/(2a)** -- compute this directly instead of using the full formula
- Always check: if a = 0, the equation is **not** quadratic (it is linear)
- In speed-distance problems: Time = Distance/Speed, and the equation typically comes from a time difference condition
