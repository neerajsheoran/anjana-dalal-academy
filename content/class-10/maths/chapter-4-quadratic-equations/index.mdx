## Introduction

Imagine a farmer in Rajasthan wants to fence a rectangular patch of land with an area of 450 square metres. The length of the patch is 5 metres more than twice its width. If the width is x metres, then the length is (2x + 5) metres.

Area = x(2x + 5) = 450, which gives **2x^2 + 5x - 450 = 0**.

This is a **quadratic equation** -- any equation where the highest power of the unknown is 2.

Quadratic equations appear naturally in problems involving areas, speeds, ages, and many other real-life situations. The ancient Indian mathematician **Brahmagupta** (7th century CE) was among the first to give general methods for solving such equations.

---

## What Is a Quadratic Equation?

A quadratic equation in the variable x has the standard form:

**ax^2 + bx + c = 0**

where a, b, c are real numbers and **a must not be zero**.

### Examples

| Equation | a | b | c | Quadratic? |
|----------|---|---|---|------------|
| 2x^2 + 5x - 450 = 0 | 2 | 5 | -450 | Yes |
| 3x^2 - 7x + 4 = 0 | 3 | -7 | 4 | Yes |
| x^2 - 8x + 15 = 0 | 1 | -8 | 15 | Yes |
| 3x + 7 = 0 | 0 | 3 | 7 | No (a = 0) |

> **Key idea:** Always simplify and rearrange an equation before deciding whether it is quadratic. Appearances can be misleading.

### Checking Whether an Equation Is Quadratic

**Example:** Is (x + 3)^3 = x^3 + 9 a quadratic equation?

Expand: x^3 + 9x^2 + 27x + 27 = x^3 + 9

Cancel x^3: 9x^2 + 27x + 18 = 0, i.e., 3x^2 + 9x + 6 = 0

Yes, it **is** quadratic!

**Example:** Is x(x + 3) + 7 = (x + 4)(x - 4) quadratic?

LHS = x^2 + 3x + 7. RHS = x^2 - 16.

Simplifying: 3x + 23 = 0.

No, this is **not** quadratic (it is linear).

## Setting Up Quadratic Equations from Word Problems

### Type 1: Area Problems

A rectangular garden has area 396 m^2. Its length is 3 metres more than twice its breadth. Find the dimensions.

Let breadth = x. Then length = 2x + 3.
- x(2x + 3) = 396
- **2x^2 + 3x - 396 = 0**

### Type 2: Number Problems

The product of two consecutive even numbers is 528. Find them.

Let the numbers be x and x + 2.
- x(x + 2) = 528
- **x^2 + 2x - 528 = 0**

### Type 3: Age Problems

Neha's father is 30 years older than her. The product of their ages 5 years from now will be 500.

Let Neha's age = x. Father's age = x + 30.
- (x + 5)(x + 35) = 500
- **x^2 + 40x + 175 - 500 = 0**, i.e., **x^2 + 40x - 325 = 0**

### Type 4: Speed-Distance Problems

A bus covers 360 km at a uniform speed. If the speed had been 10 km/h more, it would have taken 3 hours less.

Let speed = x km/h. Time = 360/x hours.
- 360/x - 360/(x + 10) = 3
- Simplifying: **x^2 + 10x - 1200 = 0**

## Solving Quadratic Equations by Factorisation

This uses the splitting-the-middle-term technique from Chapter 2.

### Steps

1. Write the equation in standard form: ax^2 + bx + c = 0
2. Find two numbers whose **product = a x c** and whose **sum = b**
3. Split the middle term using those two numbers
4. Group and factor
5. Set each factor to zero and solve

### Worked Example 1: Solve 3x^2 - 7x + 2 = 0

**Step 1:** Product = 3 x 2 = 6, Sum = -7.
Numbers: **-1 and -6** (since -1 x -6 = 6 and -1 + (-6) = -7).

**Step 2:** Split:
3x^2 - x - 6x + 2 = 0

**Step 3:** Factor:
x(3x - 1) - 2(3x - 1) = 0
(x - 2)(3x - 1) = 0

**Step 4:** Solve:
- x - 2 = 0 gives **x = 2**
- 3x - 1 = 0 gives **x = 1/3**

**Roots: x = 2 and x = 1/3**

### Worked Example 2: Solve 4x^2 + 3x - 1 = 0

Product = 4 x (-1) = -4. Sum = 3.
Numbers: 4 and -1 (since 4 x -1 = -4 and 4 + (-1) = 3).

4x^2 + 4x - x - 1 = 0
4x(x + 1) - 1(x + 1) = 0
(4x - 1)(x + 1) = 0

**Roots: x = 1/4 and x = -1**

### Worked Example 3: Find the dimensions of a hall

A prayer hall has a carpet area of 300 square metres. The length is one metre more than twice the breadth.

Equation: 2x^2 + x - 300 = 0

Product = 2 x (-300) = -600. Sum = 1.
Numbers: 25 and -24 (since 25 x -24 = -600 and 25 + (-24) = 1).

2x^2 + 25x - 24x - 300 = 0
x(2x + 25) - 12(2x + 25) = 0
(x - 12)(2x + 25) = 0

x = 12 or x = -12.5

Since breadth cannot be negative, **x = 12 m**. Length = 2(12) + 1 = **25 m**.

## Solving Quadratic Equations by Completing the Square

This technique transforms the equation into a perfect square.

### Steps

1. Start with ax^2 + bx + c = 0
2. Divide by a: x^2 + (b/a)x + c/a = 0
3. Move c/a to the right: x^2 + (b/a)x = -c/a
4. Add (b/2a)^2 to both sides
5. The left side becomes a perfect square
6. Take square roots and solve

### Worked Example: Solve x^2 - 6x + 5 = 0

**Step 1:** x^2 - 6x = -5

**Step 2:** Add (-6/2)^2 = 9 to both sides:
x^2 - 6x + 9 = -5 + 9 = 4

**Step 3:** (x - 3)^2 = 4

**Step 4:** x - 3 = +2 or x - 3 = -2

**Step 5:** x = 5 or x = 1

**Roots: x = 5 and x = 1**

## The Quadratic Formula

Completing the square on the general equation ax^2 + bx + c = 0 yields the celebrated **quadratic formula**:

**x = (-b +/- root(b^2 - 4ac)) / 2a**

This formula finds the roots of **any** quadratic equation directly.

> **Key idea:** The quadratic formula is one of the most powerful tools in Class 10 Maths. It works universally, whether the equation factorises neatly or not.

### Worked Example: Solve 5x^2 - 8x + 3 = 0

Here a = 5, b = -8, c = 3.

**Step 1:** Discriminant: b^2 - 4ac = 64 - 60 = 4

**Step 2:** Apply the formula:
x = (8 +/- root(4)) / 10 = (8 +/- 2) / 10

**Step 3:** x = (8 + 2)/10 = 1 or x = (8 - 2)/10 = 3/5

**Roots: x = 1 and x = 3/5**

## Nature of Roots -- The Discriminant

The quantity **b^2 - 4ac** is the **discriminant** of ax^2 + bx + c = 0, often written as **D**.

It reveals the nature of the roots **before you solve**:

| Discriminant (D = b^2 - 4ac) | Nature of Roots |
|-------------------------------|----------------|
| D > 0 | Two **distinct** real roots |
| D = 0 | Two **equal** real roots (one repeated root) |
| D < 0 | **No** real roots |

> **Key idea:** The discriminant acts as a quick diagnostic. Calculate D and you instantly know what kind of roots to expect.

### Worked Example 1: Find the nature of roots of 3x^2 + 5x + 4 = 0

a = 3, b = 5, c = 4

D = 25 - 48 = **-23**

Since D < 0, the equation has **no real roots**.

### Worked Example 2: Find the nature of roots of 4x^2 - 12x + 9 = 0

a = 4, b = -12, c = 9

D = 144 - 144 = **0**

Since D = 0, the equation has **two equal real roots**.

The roots are: x = -b/(2a) = 12/8 = **3/2** (both roots are 3/2)

### Worked Example 3: The Water Tank Problem

A cylindrical water tank in a Delhi housing society has a hemispherical dome. The total height is 7 metres. The internal diameter equals the total height. The difference of distances from the top and bottom of the dome to the base is 3 m. Find the height of the cylindrical part.

Let height of cylindrical portion = x metres. Then dome radius = (7 - x)/2 (... actually this becomes a geometry problem). Let us simplify:

Let the cylindrical height = x. Dome height = 7 - x. The dome's diameter equals its height: this creates the constraint. Using the given relationship:

x^2 + 7x - 60 = 0

D = 49 + 240 = **289 > 0**. Real roots exist!

x = (-7 +/- 17)/2

x = 5 or x = -12

Since height must be positive, **x = 5 m** for the cylindrical part. Dome height = **2 m**.

## Finding Values of k for Equal Roots

A classic board exam question: "Find k so that the equation has two equal roots."

For equal roots, D = 0, i.e., **b^2 - 4ac = 0**.

### Example: Find k if 3x^2 + kx + 12 = 0 has equal roots

D = k^2 - 4(3)(12) = 0
k^2 = 144
**k = +/- 12**

### Example: Find k if kx(x - 3) + 9 = 0 has equal roots

Expand: kx^2 - 3kx + 9 = 0

D = (-3k)^2 - 4(k)(9) = 0
9k^2 - 36k = 0
9k(k - 4) = 0
k = 0 or k = 4

But k = 0 would make the equation non-quadratic. So **k = 4**.

## Application Problems with Quadratic Equations

### Rectangular Wheat Field

Is it possible to design a rectangular wheat field whose length is three times its breadth and area is 675 m^2?

Let breadth = x. Length = 3x.
Area = 3x^2 = 675, so x^2 = 225, giving x = 15 m.

**Yes, it is possible.** Breadth = 15 m, Length = 45 m.

### Age Problem

The sum of ages of two cousins is 24 years. Three years ago, the product of their ages was 80. Is this situation possible?

Let ages be x and (24 - x).
Three years ago: (x - 3)(21 - x) = 80
21x - x^2 - 63 + 3x = 80
-x^2 + 24x - 143 = 0
x^2 - 24x + 143 = 0

D = 576 - 572 = **4 > 0**

**Yes, it is possible!** The roots give valid ages.

### Square Playground

Can a square playground have perimeter 64 m and area 256 m^2?

Perimeter = 4s = 64, so s = 16 m.
Area = s^2 = 256 m^2. This matches.

**Yes, it is possible.** The playground is a square of side 16 m. (D = 0 case -- equal roots.)

## Chapter Summary

1. A **quadratic equation** in x has the form **ax^2 + bx + c = 0** where a, b, c are real numbers and a is not zero.

2. A real number alpha is a **root** if a(alpha)^2 + b(alpha) + c = 0.

3. A quadratic equation has **at most two roots**.

4. **Solving by factorisation:** Split the middle term, factor by grouping, set each factor to zero.

5. **Quadratic formula:** The roots are:
   x = (-b +/- root(b^2 - 4ac)) / 2a, provided b^2 - 4ac >= 0

6. **Discriminant D = b^2 - 4ac** reveals the nature of roots:
   - D > 0: two distinct real roots
   - D = 0: two equal real roots
   - D < 0: no real roots
