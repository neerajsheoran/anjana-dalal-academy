## Key Concepts

- A pair of linear equations: **a1x + b1y + c1 = 0** and **a2x + b2y + c2 = 0**
- Each equation represents a **straight line** on the coordinate plane
- **Intersecting lines** = unique solution (consistent)
- **Coincident lines** = infinitely many solutions (dependent, consistent)
- **Parallel lines** = no solution (inconsistent)
- **Quick ratio test** to classify without solving:
  - a1/a2 **not equal to** b1/b2 --> unique solution
  - a1/a2 = b1/b2 = c1/c2 --> infinitely many solutions
  - a1/a2 = b1/b2 **not equal to** c1/c2 --> no solution
- **Substitution method**: express one variable from one equation, plug into the other
- **Elimination method**: multiply to equalize coefficients, then add/subtract to eliminate one variable
- If solving gives a **true identity** (like 24 = 24), the system has infinitely many solutions
- If solving gives a **false statement** (like 7 = 0), the system has no solution
- Equations like 3/x + 2/y = 9 can be made linear by substituting **u = 1/x, v = 1/y**
- Word problems: define variables clearly, translate sentences into equations, then solve

## Important Definitions

| Term | Meaning |
|------|---------|
| **Consistent system** | Has at least one solution (intersecting or coincident lines) |
| **Inconsistent system** | Has no solution (parallel lines) |
| **Dependent system** | Coincident lines; infinitely many solutions |
| **Substitution method** | Express one variable in terms of the other and substitute |
| **Elimination method** | Make coefficients equal, then add/subtract equations |

## Remember These

- The **ratio test** is the fastest way to check consistency without solving -- learn it well for MCQs
- In word problems, a two-digit number with tens digit x and units digit y = **10x + y** (reversed: 10y + x)
- Upstream speed = boat speed - current speed; downstream speed = boat speed + current speed
- Always verify your answer by substituting back into **both** original equations
- For fraction word problems: set numerator = x, denominator = y, then translate conditions into equations
