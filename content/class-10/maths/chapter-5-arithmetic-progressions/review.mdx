## Key Concepts

- An **AP** is a sequence where each term = previous term + a fixed **common difference (d)**
- General form: **a, a + d, a + 2d, a + 3d, ...**
- d can be **positive** (increasing), **negative** (decreasing), or **zero** (constant)
- **nth term formula**: a_n = **a + (n - 1)d**
- The nth term is also called the **general term**; the last term l = a + (m - 1)d for m terms
- **Sum of first n terms**: S_n = **n/2 [2a + (n - 1)d]** or S_n = **n/2 (a + l)** where l is the last term
- Use the first formula when d is known; use the second when the last term is known
- **Relationship**: a_n = S_n - S_(n-1) -- useful when the sum formula is given directly
- Sum of first n natural numbers = **n(n + 1)/2**
- To check if a sequence is an AP: verify all consecutive differences are equal
- To check if a value belongs to an AP: set a_n = value and check if n is a positive integer
- **Arithmetic mean** of a and c is **(a + c)/2**; then a, (a+c)/2, c form an AP

## Important Definitions

| Term | Meaning |
|------|---------|
| **Arithmetic Progression (AP)** | Sequence with a constant difference between consecutive terms |
| **Common difference (d)** | The fixed value added to get the next term: d = a2 - a1 |
| **First term (a)** | The starting term of the AP |
| **General term (a_n)** | The nth term: a + (n - 1)d |
| **Finite AP** | AP with a definite number of terms |
| **Arithmetic Mean** | Middle value of three terms in AP: b = (a + c)/2 |

## Remember These

- If n turns out to be a **non-integer** or **negative**, the value is NOT a term of that AP
- When given two terms (say 4th and 8th), set up two equations in a and d, subtract to find d first
- For "how many terms give sum S" problems, you get a quadratic in n -- reject the non-integer solution
- Three-digit numbers divisible by k form an AP: first term = smallest 3-digit multiple, last = largest, d = k
- The sum formula can yield **negative values** if d is negative and n is large enough
