## Key Concepts

- An object is in **motion** when its position changes over time relative to a **reference point**
- Motion is **relative** -- depends on the observer's frame of reference
- **Distance** = total path length (scalar, always positive); **displacement** = straight-line from start to finish with direction (vector, can be zero or negative)
- Distance >= magnitude of displacement; they are equal only for straight-line motion without reversal
- **Uniform motion**: equal distances in equal time intervals; **non-uniform motion**: unequal distances
- **Speed** = distance / time (scalar); **velocity** = displacement / time (vector)
- **Average speed** = total distance / total time
- **Average velocity** = (u + v) / 2 (valid for uniform acceleration)
- **Acceleration** = (v - u) / t; SI unit: m/s²
- Positive acceleration = speeding up; negative acceleration (retardation) = slowing down; zero acceleration = uniform motion
- **Uniform acceleration**: velocity changes by equal amounts every second
- Slope of **distance-time graph** = speed; slope of **velocity-time graph** = acceleration
- **Area under velocity-time graph** = distance travelled

## Three Equations of Motion (Uniform Acceleration)

| Equation | Connects |
|----------|----------|
| **v = u + at** | velocity, initial velocity, acceleration, time |
| **s = ut + ½at²** | displacement, initial velocity, acceleration, time |
| **v² = u² + 2as** | velocity, initial velocity, acceleration, displacement |

Where: u = initial velocity, v = final velocity, a = acceleration, t = time, s = displacement

## Uniform Circular Motion

- Object moves in a circle at **constant speed** but **changing velocity** (direction changes continuously)
- Speed for one revolution: **v = 2πr / t**
- Examples: Moon orbiting Earth, tip of clock hand, child on merry-go-round

## Important Definitions

| Term | Meaning |
|------|---------|
| Distance | Total length of path travelled (scalar) |
| Displacement | Shortest straight-line gap from start to finish, with direction (vector) |
| Speed | Distance per unit time (scalar); SI unit: m/s |
| Velocity | Displacement per unit time (vector); SI unit: m/s |
| Acceleration | Rate of change of velocity; SI unit: m/s² |
| Uniform motion | Equal distances in equal time intervals |
| Non-uniform motion | Unequal distances in equal time intervals |

## Remember These

- **1 km/h = 5/18 m/s** (multiply km/h by 5/18 to convert)
- If an object returns to its starting point, displacement = 0, but distance is NOT zero
- Constant speed on a circular path does **not** mean constant velocity -- direction keeps changing, so there is always acceleration
- Each equation of motion uses 4 of the 5 variables (u, v, a, t, s) -- pick the equation that includes your unknown
