## Key Concepts

- **Motion** = change in position of an object relative to a chosen **reference point**
- A complete description of position needs distance AND direction from the reference point
- **Distance** = total length of path travelled (scalar — no direction)
- **Displacement** = straight-line gap from start to end, WITH direction (vector)
- A round trip can give large distance but zero displacement (end at the start)
- **Speed** = distance ÷ time (scalar). SI unit: m/s
- **Velocity** = displacement ÷ time (vector — has direction). SI unit: m/s
- **Uniform motion** = covers equal distances in equal time intervals (constant speed)
- **Non-uniform motion** = speed changes over time
- **Average speed** = total distance ÷ total time. **Average velocity** = total displacement ÷ total time
- **Acceleration** = change in velocity ÷ time taken. SI unit: m/s²
- Positive acceleration = speeding up. Negative acceleration (also called retardation or deceleration) = slowing down
- An object turning at constant speed IS accelerating because direction (and so velocity) is changing
- **Position-time graph**: slope of the line = velocity. Horizontal line = at rest. Slanting line = uniform motion. Curve = non-uniform motion
- **Velocity-time graph**: slope = acceleration. Area under the curve = distance travelled
- Three equations of motion for uniform acceleration in a straight line:
  - **v = u + at**
  - **s = ut + ½at²**
  - **v² = u² + 2as**
- **Uniform circular motion**: constant speed but changing direction means the object is accelerating

## Important Definitions

| Term | Meaning |
|------|---------|
| Reference point | A fixed point from which positions are measured |
| Distance | Total path length covered (scalar) |
| Displacement | Net change in position from start to end (vector) |
| Speed | Distance covered per unit time |
| Velocity | Displacement per unit time (has direction) |
| Uniform motion | Object covers equal distances in equal time intervals |
| Acceleration | Rate of change of velocity |
| Retardation | Negative acceleration (slowing down) |
| Scalar | Quantity with magnitude only (e.g., distance, speed) |
| Vector | Quantity with magnitude AND direction (e.g., displacement, velocity, acceleration) |
| Uniform circular motion | Motion along a circular path at constant speed |

## Remember These

- **Distance is scalar; displacement is vector.** Distance ≥ |displacement| always
- **Speed is scalar; velocity is vector.** A car turning a corner has constant speed but changing velocity
- **Negative velocity** in a problem means motion in the opposite direction, NOT that the object is below zero somewhere
- **Acceleration is the change in velocity, not the change in speed** — turning at constant speed still means accelerating
- The **slope** of a position-time graph = speed/velocity
- The **area** under a velocity-time graph = distance/displacement
- For a ball thrown straight up at 20 m/s, at the very top the velocity is **zero** but acceleration is still **g = 9.8 m/s² downward**
