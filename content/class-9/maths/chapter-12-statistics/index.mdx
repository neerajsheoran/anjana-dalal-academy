## Introduction

Every time you check the weather forecast, look at a cricket scorecard, or read about election results, you are consuming **statistics**. The word traces back to the Latin *status* (meaning "state"), because governments were among the first to collect and organise data -- counting citizens, recording harvests, and tracking revenues. Today, statistics powers everything from medical research to app recommendations.

In this chapter, you will learn to organise raw data into tables, display it using **bar graphs**, **histograms**, and **frequency polygons**, and summarise it with three key numbers: the **mean**, the **median**, and the **mode**.

---

## Collecting and Organising Data

**Data** refers to facts or figures gathered for a specific purpose.

* **Primary data:** Information you collect yourself -- for example, surveying your classmates about how many hours they study each day.
* **Secondary data:** Information already collected by someone else -- census reports, weather records, published studies.

### Building a Frequency Distribution

When a data set has many values, listing every single observation is unwieldy. Instead, we create a **frequency distribution table**.

* **Ungrouped distribution:** Each distinct value appears with its count (frequency).
* **Grouped distribution:** Values are bundled into **class intervals** (such as 0--10, 10--20, etc.), and the frequency of each interval is recorded.

Important terminology for grouped data:

* **Class interval:** A range like 10--20. Here 10 is the **lower class limit** and 20 is the **upper class limit**.
* **Class size (width):** Upper limit minus lower limit (e.g., 20 - 10 = 10).
* **Class mark (midpoint):** (Lower limit + Upper limit) / 2. For 10--20, the class mark is 15.
* **Frequency:** How many observations fall into a given interval.

## Displaying Data Graphically

### Bar Graphs

A **bar graph** uses rectangles of equal width, separated by gaps, to represent categories. The height of each bar shows the value or frequency. Bar graphs suit **discrete** or **categorical** data -- like the number of students in each school house or the favourite sport of a class.

### Histograms

![Sample histogram with continuous class intervals on the x-axis and frequency on the y-axis, with no gaps between bars](histogram-example.png)

A **histogram** looks like a bar graph but has **no gaps** between the bars, because it represents **continuous** data grouped into class intervals.

Key differences from a bar graph:
* Bars touch each other (no spacing).
* Each bar's width matches its class size.
* When class widths vary, the bar height is set to **frequency / class width** (called **frequency density**), so that the **area** of the bar -- not just its height -- represents the frequency.

> **Watch out:** Unequal class widths are a common exam trap. If you use raw frequency as the height when widths differ, your histogram will be misleading. Always check whether the class widths are uniform before drawing.

### Frequency Polygons

A **frequency polygon** is constructed by:

1. Calculating the **class mark** (midpoint) for each interval.
2. Plotting each (class mark, frequency) pair as a point.
3. Connecting the points with straight line segments.
4. Closing the polygon at both ends by extending to the midpoints of imaginary classes (with frequency 0) just before the first class and just after the last class.

You can also draw a frequency polygon over a histogram by simply connecting the midpoints of the top edges of adjacent bars.

![Frequency polygon overlaid on a histogram, showing how the midpoints of bar tops are connected](frequency-polygon-over-histogram.png)

> **Advantage:** Frequency polygons make it easy to compare two different data distributions on the same axes -- something that is awkward with histograms.

## Measures of Central Tendency

A **measure of central tendency** condenses an entire data set into one representative number. The three standard measures are the **mean**, the **median**, and the **mode**.

![Comparison diagram showing mean, median, and mode marked on a data distribution](mean-median-mode-comparison.png)

### Mean (Arithmetic Average)

The **mean** is the total of all observations divided by the count.

**Ungrouped data:**

Mean = (x₁ + x₂ + ... + xₙ) / n

**Frequency distribution:**

If values x₁, x₂, ..., xₖ occur with frequencies f₁, f₂, ..., fₖ:

Mean = (f₁x₁ + f₂x₂ + ... + fₖxₖ) / (f₁ + f₂ + ... + fₖ)

**Example:** The marks of five students are 12, 15, 18, 20, 25. Find the mean.

Mean = (12 + 15 + 18 + 20 + 25) / 5 = 90 / 5 = **18**

> **Keep in mind:** The mean takes every single value into account, which makes it sensitive to extreme values (outliers). One unusually large or small observation can pull the mean away from the "typical" value.

### Median

The **median** is the middle value once the data is sorted in ascending order.

* If n is **odd**: Median = the ((n + 1) / 2)th observation.
* If n is **even**: Median = average of the (n / 2)th and the (n / 2 + 1)th observations.

**Example (odd n):** Data: 11, 14, 17, 21, 30. n = 5. Median = 3rd value = **17**.

**Example (even n):** Data: 5, 8, 12, 15. n = 4. Median = (8 + 12) / 2 = **10**.

> **Advantage:** The median is not pulled around by outliers. If you have one extremely high income in a village, the median income stays close to what most families actually earn, while the mean shoots up.

### Mode

The **mode** is the value that appears **most often**.

**Example:** Goals scored in 8 matches: 1, 2, 2, 3, 2, 4, 0, 3. The value 2 appears three times (more than any other). Mode = **2**.

A data set can be **unimodal** (one mode), **bimodal** (two modes), **multimodal**, or have **no mode** if every value occurs equally often.

> **Unique feature:** The mode is the only central tendency measure that works for **categorical** data. You can find the mode of favourite colours or preferred languages, but you cannot meaningfully compute a mean or median for them.

## Summary

1. **Statistics** is the science of collecting, organising, analysing, and presenting data.
2. Data can be shown using **bar graphs** (discrete data), **histograms** (continuous grouped data), and **frequency polygons** (midpoints joined by lines).
3. In histograms with unequal class widths, use **frequency density** (frequency / class width) for bar heights.
4. **Mean** = sum of observations / number of observations. Sensitive to outliers.
5. **Median** = middle value of sorted data. Robust against outliers.
6. **Mode** = most frequently occurring value. Works even for non-numeric data.
