## Key Concepts

- **Statistics** is the science of collecting, organising, analysing, and presenting data
- **Primary data:** collected firsthand by you; **Secondary data:** collected by someone else
- **Ungrouped frequency distribution:** each distinct value listed with its count
- **Grouped frequency distribution:** values bundled into **class intervals** with frequencies
- **Class interval** has a lower limit and upper limit; **Class size** = upper - lower
- **Class mark (midpoint)** = (lower limit + upper limit) / 2
- **Bar graph:** equal-width bars with gaps; used for discrete/categorical data
- **Histogram:** bars with **no gaps**; used for continuous grouped data
- For **unequal class widths**, use **frequency density** (frequency / class width) as bar height
- **Frequency polygon:** plot (class mark, frequency), connect with lines, close at both ends with zero-frequency points
- **Mean** = sum of all observations / total number of observations
- For frequency data: **Mean = Σ(f × x) / Σf**
- **Median** = middle value when data is sorted; for odd n: ((n+1)/2)th value; for even n: average of (n/2)th and (n/2+1)th values
- **Mode** = most frequently occurring value; works for categorical data too
- Mean is sensitive to **outliers**; median is **robust** against outliers

## Important Definitions

| Term | Meaning |
|------|---------|
| **Frequency** | The number of times a value or class interval occurs |
| **Class interval** | A range grouping data values (e.g., 10-20) |
| **Class mark** | Midpoint of a class interval |
| **Frequency density** | Frequency / class width (used for unequal widths) |
| **Mean** | Sum of observations / number of observations |
| **Median** | The middle value in sorted data |
| **Mode** | The value with the highest frequency |

## Measures of Central Tendency

| Measure | Formula / Method | Best Used When |
|---------|-----------------|----------------|
| **Mean** | Σx / n (or Σfx / Σf) | All values are important, no extreme outliers |
| **Median** | Middle value of sorted data | Data has outliers or is skewed |
| **Mode** | Most frequent value | Categorical data or finding the most common value |

## Remember These

- In histograms with **unequal class widths**, the **area** (not height) represents frequency -- use frequency density
- A data set can have **no mode**, **one mode**, or **multiple modes** -- but mean and median are always unique
- Always **sort data** before finding the median -- forgetting to sort is a common exam mistake
- Frequency polygon must be **closed** at both ends by adding imaginary classes with frequency 0
- Mean uses **every** data point, so one extreme value can distort it significantly
