## Introduction

In previous classes, you worked with algebraic expressions -- adding, subtracting, multiplying, and factorising them. You also encountered identities such as (a + b)^2 = a^2 + 2ab + b^2 and a^2 - b^2 = (a + b)(a - b). This chapter introduces you to a well-defined family of algebraic expressions called **polynomials**. You will discover how to find their zeroes, use powerful theorems for division and factorisation, and master new identities that extend your algebraic toolkit.

---

## Polynomials in One Variable

A **variable** is a letter (such as x, y, or t) that can represent any real number. A **polynomial in one variable** x is an algebraic expression where every term contains x raised to a **whole number** exponent.

The general form of a polynomial of degree n is:

**p(x) = a\_n x^n + a\_(n-1) x^(n-1) + ... + a\_1 x + a\_0**

where a\_0, a\_1, ..., a\_n are real number constants and a\_n is not zero.

> **Key idea:** Expressions such as x + 1/x, sqrt(x) + 5, or 4sqrt(t) + t^3 do NOT qualify as polynomials because at least one term has an exponent that is not a whole number.

### Terminology

* **Terms:** The building blocks of a polynomial, separated by + or - signs. In 3x^3 - 5x^2 + 2x - 8, the terms are 3x^3, -5x^2, 2x, and -8.
* **Coefficient:** The numerical multiplier of each term. In 3x^3, the coefficient is 3. In -5x^2, the coefficient is -5.
* **Degree:** The largest exponent of x present in the polynomial. The degree of 4x^5 - x^3 + 2x + 6 is **5**.
* A non-zero constant polynomial (like 9) has degree **0**.
* The **zero polynomial** has no defined degree.

### Grouping by number of terms

| Name          | Terms | Examples                     |
| ------------- | ----- | ---------------------------- |
| **Monomial**  | 1     | 7x^4, -3, y                 |
| **Binomial**  | 2     | x + 5, x^2 - 3x             |
| **Trinomial** | 3     | x^2 + 4x + 4, 1 - x + x^2  |

### Grouping by degree

| Name          | Degree | General Form                     |
| ------------- | ------ | -------------------------------- |
| **Linear**    | 1      | ax + b (a not 0)                 |
| **Quadratic** | 2      | ax^2 + bx + c (a not 0)         |
| **Cubic**     | 3      | ax^3 + bx^2 + cx + d (a not 0)  |

## Zeroes of a Polynomial

When we substitute a real number c into p(x) and get **p(c) = 0**, we call c a **zero** (or **root**) of the polynomial.

**Example:** Take p(x) = x - 3. Since p(3) = 3 - 3 = 0, the number 3 is a zero of this polynomial.

**Example:** Take p(x) = x^2 - 5x. Both x = 0 and x = 5 are zeroes because p(0) = 0 and p(5) = 25 - 25 = 0.

### Zeroes of linear polynomials

For p(x) = ax + b (a not 0), set ax + b = 0 to get **x = -b/a**. This is the only zero.

> **Key idea:** A linear polynomial has exactly one zero. A non-zero constant polynomial has no zeroes at all. The zero polynomial has every real number as a zero.

In general, a polynomial of degree n can have **at most n** zeroes.

## Remainder Theorem

Dividing a polynomial p(x) by a linear expression (x - a) produces a quotient q(x) and a constant remainder r:

**p(x) = (x - a) q(x) + r**

![Visual representation of polynomial division showing dividend, divisor, quotient, and remainder](polynomial-division-diagram.png)

The **Remainder Theorem** tells us:

> **Key idea:** If p(x) is a polynomial of degree at least 1 and a is any real number, then the remainder when p(x) is divided by (x - a) equals **p(a)**.

**Example:** Find the remainder when p(x) = x^3 + 3x^2 - 5x + 2 is divided by (x - 2).

By the Remainder Theorem, remainder = p(2) = 8 + 12 - 10 + 2 = 12.

**Example:** Find the remainder when p(x) = 3x^3 - 4x^2 + 2x - 1 is divided by (3x - 1), i.e., by (x - 1/3).

Remainder = p(1/3) = 3(1/27) - 4(1/9) + 2(1/3) - 1 = 1/9 - 4/9 + 2/3 - 1 = -2/3.

## Factor Theorem

The **Factor Theorem** follows directly from the Remainder Theorem:

> **Key idea:** For a polynomial p(x) of degree n >= 1, **(x - a) is a factor of p(x) if and only if p(a) = 0**.

This means:

* If p(a) = 0, then (x - a) divides p(x) exactly.
* If (x - a) is a factor, then p(a) must be 0.

**Example:** Is (x + 2) a factor of x^3 + 3x^2 + 3x + 2?

Check p(-2) = (-2)^3 + 3(-2)^2 + 3(-2) + 2 = -8 + 12 - 6 + 2 = 0. Yes, (x + 2) is a factor.

**Example:** Find the value of m if (x - 2) is a factor of 3x^3 - x^2 + mx + 4.

Since (x - 2) is a factor, p(2) = 0. So 24 - 4 + 2m + 4 = 0, giving 2m = -24, hence m = -12.

## Factorisation of Polynomials

### Splitting the middle term for quadratics

To factorise ax^2 + bx + c, search for two numbers p and q satisfying:

* p + q = b
* p times q = a times c

Then rewrite the middle term bx as px + qx, and factor by grouping.

**Example:** Factorise 10x^2 + 11x + 3.

We need two numbers summing to 11 with product 30 (= 10 times 3). The pair is 5 and 6.

10x^2 + 11x + 3 = 10x^2 + 5x + 6x + 3 = 5x(2x + 1) + 3(2x + 1) = **(2x + 1)(5x + 3)**

**Example:** Factorise 8x^2 - 14x + 3.

Product = 24, sum = -14. The pair is -2 and -12.

8x^2 - 14x + 3 = 8x^2 - 2x - 12x + 3 = 2x(4x - 1) - 3(4x - 1) = **(2x - 3)(4x - 1)**

### Factorising cubics

For cubic polynomials, first apply the Factor Theorem to discover one linear factor, then factorise the remaining quadratic.

**Example:** Factorise x^3 - 4x^2 + x + 6.

Try x = 2: p(2) = 8 - 16 + 2 + 6 = 0. So (x - 2) is a factor.

Dividing: x^3 - 4x^2 + x + 6 = (x - 2)(x^2 - 2x - 3) = (x - 2)(x - 3)(x + 1)

**Example:** Factorise x^3 + 6x^2 + 11x + 6.

Try x = -1: p(-1) = -1 + 6 - 11 + 6 = 0. So (x + 1) is a factor.

x^3 + 6x^2 + 11x + 6 = (x + 1)(x^2 + 5x + 6) = **(x + 1)(x + 2)(x + 3)**

## Algebraic Identities

### Previously known identities

* **Identity I:** (x + y)^2 = x^2 + 2xy + y^2
* **Identity II:** (x - y)^2 = x^2 - 2xy + y^2
* **Identity III:** x^2 - y^2 = (x + y)(x - y)
* **Identity IV:** (x + a)(x + b) = x^2 + (a + b)x + ab

### New identities

![Geometric interpretation of the identity (x + y)^2 = x^2 + 2xy + y^2 shown as areas in a square](square-of-sum-geometric-proof.png)

* **Identity V:** (x + y + z)^2 = x^2 + y^2 + z^2 + 2xy + 2yz + 2zx
* **Identity VI:** (x + y)^3 = x^3 + y^3 + 3xy(x + y) = x^3 + 3x^2y + 3xy^2 + y^3
* **Identity VII:** (x - y)^3 = x^3 - y^3 - 3xy(x - y) = x^3 - 3x^2y + 3xy^2 - y^3
* **Identity VIII:** x^3 + y^3 + z^3 - 3xyz = (x + y + z)(x^2 + y^2 + z^2 - xy - yz - zx)

> **Key idea:** When x + y + z = 0, Identity VIII simplifies to x^3 + y^3 + z^3 = 3xyz.

### Expansion using identities

**Example:** Expand (2p + 5q + 3r)^2.

Using Identity V: = 4p^2 + 25q^2 + 9r^2 + 20pq + 30qr + 12pr

**Example:** Expand (3x + 2)^3.

Using Identity VI: = 27x^3 + 8 + 18x(3x + 2) = 27x^3 + 54x^2 + 36x + 8

**Example:** Expand (3a - 2b)^3.

Using Identity VII: = 27a^3 - 8b^3 - 18ab(3a - 2b) = 27a^3 - 8b^3 - 54a^2b + 36ab^2

### Evaluation using identities

**Example:** Evaluate (98)^3.

98^3 = (100 - 2)^3 = 1000000 - 8 - 600(98) = 1000000 - 8 - 58800 = **941192**

**Example:** Evaluate (103)^3.

103^3 = (100 + 3)^3 = 1000000 + 27 + 900(103) = 1000000 + 27 + 92700 = **1092727**

### Factorisation using identities

**Example:** Factorise 27a^3 + b^3 + 9a^2b + 3ab^2.

\= (3a)^3 + b^3 + 3(3a)^2(b) + 3(3a)(b)^2 = **(3a + b)^3**

**Example:** Factorise 8y^3 + 125z^3.

Using x^3 + y^3 = (x + y)(x^2 - xy + y^2):

\= (2y)^3 + (5z)^3 = **(2y + 5z)(4y^2 - 10yz + 25z^2)**

**Example:** Factorise 8x^3 + y^3 + z^3 - 6xyz.

\= (2x)^3 + y^3 + z^3 - 3(2x)(y)(z) = **(2x + y + z)(4x^2 + y^2 + z^2 - 2xy - yz - 2xz)**

### Special shortcut

When x + y + z = 0, then x^3 + y^3 + z^3 = 3xyz.

**Example:** Calculate (-15)^3 + 8^3 + 7^3.

Since -15 + 8 + 7 = 0, the answer = 3(-15)(8)(7) = **-2520**.

## Summary

1. A **polynomial** p(x) in one variable x has the form a\_n x^n + ... + a\_1 x + a\_0 where a\_n is not 0.
2. Polynomials are grouped as **monomials** (1 term), **binomials** (2 terms), or **trinomials** (3 terms).
3. By degree: **linear** (degree 1), **quadratic** (degree 2), **cubic** (degree 3).
4. A real number a is a **zero** of p(x) if p(a) = 0.
5. Every linear polynomial has exactly one zero.
6. **Factor Theorem:** (x - a) is a factor of p(x) if and only if p(a) = 0.
7. Key identities: (x + y + z)^2, (x + y)^3, (x - y)^3, and x^3 + y^3 + z^3 - 3xyz.
