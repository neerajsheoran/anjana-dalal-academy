## Key Concepts

- A **polynomial in x** has terms with whole number exponents only: a_n x^n + ... + a_1 x + a_0
- Expressions with 1/x, √x, or negative exponents are **not** polynomials
- **Degree** = highest exponent of the variable; degree of a non-zero constant = 0
- **Monomial** (1 term), **Binomial** (2 terms), **Trinomial** (3 terms)
- **Linear** (degree 1), **Quadratic** (degree 2), **Cubic** (degree 3)
- A **zero/root** of p(x) is a value c where p(c) = 0
- A linear polynomial ax + b has exactly **one** zero: x = -b/a
- A polynomial of degree n has **at most n** zeroes
- **Remainder Theorem:** remainder when p(x) is divided by (x - a) = **p(a)**
- **Factor Theorem:** (x - a) is a factor of p(x) **if and only if** p(a) = 0
- To factorise a quadratic, **split the middle term**: find two numbers with sum = b and product = a × c
- To factorise a cubic, use Factor Theorem to find one root, then factorise the remaining quadratic
- **Identity V:** (x + y + z)² = x² + y² + z² + 2xy + 2yz + 2zx
- **Identity VI:** (x + y)³ = x³ + y³ + 3xy(x + y)
- **Identity VII:** (x - y)³ = x³ - y³ - 3xy(x - y)
- **Identity VIII:** x³ + y³ + z³ - 3xyz = (x + y + z)(x² + y² + z² - xy - yz - zx)
- **Special case:** If x + y + z = 0, then x³ + y³ + z³ = 3xyz

## Important Definitions

| Term | Meaning |
|------|---------|
| **Polynomial** | Expression with whole-number exponents of a variable |
| **Degree** | Highest power of the variable in the polynomial |
| **Zero of a polynomial** | Value of x that makes p(x) = 0 |
| **Coefficient** | The numerical multiplier of a term |
| **Factor** | (x - a) is a factor if it divides p(x) with zero remainder |

## Remember These

- The **zero polynomial** has no defined degree -- do not confuse with degree 0
- SSA-style mistake: for Factor Theorem, check p(a) = 0, not p(-a) -- sign matters based on the factor
- When x + y + z = 0 → x³ + y³ + z³ = 3xyz -- very common in exam problems
- Splitting the middle term: product = a × c (first × last coefficient), sum = b (middle coefficient)
- x³ + y³ = (x + y)(x² - xy + y²) and x³ - y³ = (x - y)(x² + xy + y²)
