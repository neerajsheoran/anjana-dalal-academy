## Introduction

In earlier classes, you worked with **linear equations in one variable** -- equations like 3x + 5 = 0 or 2y - 7 = 0, each having exactly one solution. This chapter broadens the picture to **linear equations in two variables**. You will learn how to set them up, discover that they have infinitely many solutions, and see how each such equation paints a straight line on the Cartesian plane.

---

## Linear Equations

A **linear equation in two variables** takes the form:

**ax + by + c = 0**

where **a**, **b**, and **c** are real numbers, and **a** and **b** are not both zero.

> **Key idea:** "Linear" means every variable appears with power 1 only. There are no squared terms like x^2, no products like xy, and no square roots of variables.

### Examples

* 3x + 5y = 18 can be rewritten as 3x + 5y - 18 = 0 (a = 3, b = 5, c = -18)
* x - y/4 - 7 = 0 (a = 1, b = -1/4, c = -7)
* -5x + 2y = 3 can be rewritten as -5x + 2y - 3 = 0 (a = -5, b = 2, c = -3)
* y = 4x can be rewritten as -4x + y + 0 = 0 (a = -4, b = 1, c = 0)
* 3x + 7y = 0 (a = 3, b = 7, c = 0)
* 5x + 1 = 0 can be rewritten as 5x + 0.y + 1 = 0 (a = 5, b = 0, c = 1)
* y - 5 = 0 can be rewritten as 0.x + y - 5 = 0 (a = 0, b = 1, c = -5)

> **Key idea:** A linear equation in one variable like ax + b = 0 is just a special case: ax + 0.y + b = 0. Similarly, y = 5 is really 0.x + 1.y - 5 = 0.

## Solution of a Linear Equation in Two Variables

A **solution** is a pair of values -- one for x and one for y -- that makes the equation true. We write it as an **ordered pair (x, y)**.

**Example:** Consider 3x + 4y = 24.

* (0, 6) is a solution because 3(0) + 4(6) = 0 + 24 = 24.
* (8, 0) is a solution because 3(8) + 4(0) = 24 + 0 = 24.
* (4, 3) is a solution because 3(4) + 4(3) = 12 + 12 = 24.
* (2, 5) is NOT a solution because 3(2) + 4(5) = 6 + 20 = 26, which is not 24.

> **Key idea:** A linear equation in two variables has **infinitely many solutions**. Pick any value for one variable, and the equation determines the value of the other.

### Finding solutions systematically

**Method:** Choose a convenient value for one variable, substitute into the equation, and solve for the other.

**Example:** Find four solutions of 2x + 3y = 18.

| Choose | Substitute    | Solve  | Solution |
| ------ | ------------- | ------ | -------- |
| x = 0  | 0 + 3y = 18  | y = 6  | (0, 6)   |
| y = 0  | 2x + 0 = 18  | x = 9  | (9, 0)   |
| x = 3  | 6 + 3y = 18  | y = 4  | (3, 4)   |
| y = 2  | 2x + 6 = 18  | x = 6  | (6, 2)   |

## Graph of a Linear Equation in Two Variables

Every linear equation in two variables traces a **straight line** on the Cartesian plane. Each point on that line satisfies the equation, and every pair satisfying the equation lies on that line.

### Drawing the graph

1. Calculate at least **two solutions** of the equation.
2. Plot those solutions as points on the Cartesian plane.
3. Connect the points with a straight line and extend it in both directions with arrows.

**Example:** Draw the graph of x + y = 9.

Some solutions: (0, 9), (9, 0), (4, 5). Plot these and draw a straight line through them.

![Graph of the linear equation x + y = 7 plotted on the Cartesian plane with points (0,7), (7,0), and (3,4) marked](graph-linear-equation-x-plus-y-equals-7.png)

### Special cases

* The equation **x = a** (a constant) is a vertical line running parallel to the y-axis, crossing the x-axis at a.
* The equation **y = b** (a constant) is a horizontal line running parallel to the x-axis, crossing the y-axis at b.
* The equation **y = mx** (no constant term) is a line passing through the origin.

**Example:** x = 5 is a vertical line through (5, 0).

**Example:** y = -3 is a horizontal line through (0, -3).

![Graph showing x = 3 as a vertical line and y = -2 as a horizontal line on the Cartesian plane](lines-parallel-to-axes.png)

> **Key idea:** Every point on the graph satisfies the equation. Every pair that satisfies the equation is a point on the graph.

---

## Equations of Lines Parallel to the Axes

* **Lines parallel to the x-axis** have the equation **y = k** for some constant k. Every point on such a line shares the same y-coordinate.
* **Lines parallel to the y-axis** have the equation **x = k** for some constant k. Every point on such a line shares the same x-coordinate.
* The **x-axis itself** is described by y = 0.
* The **y-axis itself** is described by x = 0.

---

## Summary

1. An equation of the form **ax + by + c = 0** (a, b, c are real numbers; a, b not both zero) is a **linear equation in two variables**.
2. A linear equation in two variables has **infinitely many solutions**.
3. The graph of such an equation is always a **straight line**.
4. Every point on the line solves the equation, and every solution of the equation lies on the line.
5. The equation **y = mx** represents a line through the origin.
6. The equation **x = a** is a vertical line; **y = b** is a horizontal line.
