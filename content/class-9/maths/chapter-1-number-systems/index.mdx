## Introduction

Think about counting mangoes in a basket -- you start with 1, 2, 3, and so on. These counting numbers have been with us since childhood. But as mathematics grew, so did our need for more types of numbers. What happens when the basket is empty? We need zero. What about a debt of Rs 500? We need negative numbers. What about splitting a roti equally among 3 people? We need fractions. This chapter takes you on a journey through the entire family of numbers, all the way to the **real number system**.

The number family is like a joint family -- each generation contains the previous one:

![Venn diagram showing the nested hierarchy of number sets: natural numbers inside whole numbers inside integers inside rational numbers inside real numbers](number-sets-venn-diagram.png)

* **Natural Numbers (N):** The counting numbers 1, 2, 3, 4, ... that stretch endlessly.
* **Whole Numbers (W):** When we include zero with the natural numbers: 0, 1, 2, 3, ...
* **Integers (Z):** Whole numbers along with their negatives: ..., -3, -2, -1, 0, 1, 2, 3, ... (Z stands for "Zahlen," a German word for numbers.)
* **Rational Numbers (Q):** Any number expressible as p/q, with p and q being integers and q not zero. (Q stands for "quotient.")

> **Key idea:** Each number set nests inside the next. Every natural number is also a whole number, every whole number is also an integer, and every integer is also a rational number (since any integer n can be written as n/1).

## Rational Numbers

A number **r** is **rational** if we can express it as **p/q**, where p and q are integers and q is not zero.

Think of it this way: if you can write a number as one integer divided by another (non-zero) integer, it is rational. So -17 is rational (write it as -17/1), and 0.75 is rational (write it as 3/4).

A rational number does not have a single unique form. For example:

2/3 = 4/6 = 8/12 = 20/30

When placing p/q on the number line, we typically use the **simplest form** -- where p and q share no common factor other than 1.

**Locating rational numbers between two given numbers:**

Between any two rational numbers, there are **infinitely many** other rational numbers. Two practical ways to find them:

1. **Mean method:** The number (r + s)/2 always lies exactly between r and s.
2. **Equivalent fraction method:** To find n rational numbers between two values, rewrite both with a common denominator of (n + 1) or larger, then pick numerators in between.

**Example:** Locate four rational numbers between 2 and 3.

Rewrite 2 = 10/5 and 3 = 15/5. The four rational numbers are 11/5, 12/5, 13/5, and 14/5.

## Irrational Numbers

Even after placing every rational number on the number line, countless "holes" remain. The numbers that fill these holes are called **irrational numbers**.

A number **s** is **irrational** if it **cannot** be expressed as p/q for any integers p and q (with q not zero).

> **Key idea:** The ancient Indian text Sulbasutras (around 800 BC) contains remarkably accurate approximations of sqrt(2), needed for constructing Vedic fire altars. The Greek mathematician Hippasus is credited with the formal proof that sqrt(2) cannot be a ratio of integers.

Some well-known irrational numbers:

* Square roots of non-perfect squares: sqrt(2), sqrt(3), sqrt(5), sqrt(7), ...
* The constant pi (approximately 3.14159265...)
* Decimals with no end and no repeating block, such as 0.20220222022220...

**Placing sqrt(2) on the number line:**

Imagine a square with each side measuring 1 unit. By the Pythagoras theorem, the diagonal measures sqrt(1^2 + 1^2) = sqrt(2). Position this square so one corner sits at the origin on the number line. Using a compass with the diagonal as radius, swing an arc to mark a point on the number line. That point is sqrt(2).

![Construction showing a unit square on the number line with its diagonal used to locate sqrt(2) using a compass arc](locating-sqrt2-number-line.png)

**Placing sqrt(3) on the number line:**

After locating sqrt(2), build a right triangle with one leg = sqrt(2) and the other = 1. The hypotenuse = sqrt(2 + 1) = sqrt(3). Transfer this length to the number line using a compass.

![Successive construction of sqrt(2), sqrt(3), sqrt(4) on the number line using right triangles (spiral of Theodorus approach)](successive-square-roots-number-line.png)

By repeating this process, sqrt(n) for any positive integer n can be placed on the number line once sqrt(n - 1) is already located.

## Real Numbers

Combine **all rational numbers** with **all irrational numbers**, and you get the set of **real numbers**, written as **R**.

> **Key idea:** There is a perfect one-to-one match between real numbers and points on the number line. Every real number sits at exactly one point, and every point corresponds to exactly one real number. This is why we call it the **real number line**.

This deep result was formalized by the German mathematicians **Cantor** and **Dedekind** around the 1870s.

Every real number falls into exactly one category -- it is either rational or irrational, with no overlap and no gaps.

## Decimal Expansions of Real Numbers

Decimals give us a powerful lens for distinguishing rational from irrational numbers.

### Decimals of rational numbers

When you carry out the division p divided by q, one of two outcomes occurs:

**Outcome 1: Terminating decimal** -- The division ends with remainder zero.

* 3/8 = 0.375
* 7/4 = 1.75
* 141/250 = 0.564

**Outcome 2: Non-terminating recurring (repeating) decimal** -- At some point, a group of digits begins repeating endlessly.

* 7/3 = 2.333... = 2.3 (bar over 3)
* 5/11 = 0.454545... = 0.45 (bar over 45)

> **Key idea:** A rational number always produces either a terminating decimal or a non-terminating recurring decimal. And conversely, any decimal that terminates or repeats is rational.

### Decimals of irrational numbers

Irrational numbers produce decimals that are **non-terminating and non-recurring** -- they go on forever without ever settling into a repeating pattern.

* sqrt(2) = 1.41421356237...
* pi = 3.14159265358...

> **Key idea:** If a decimal expansion never ends and never repeats, the number is irrational. If it terminates or repeats, the number is rational.

### Turning recurring decimals into fractions

**Example:** Write 0.444... as p/q.

Let x = 0.444...
Then 10x = 4.444... = 4 + x
So 9x = 4, giving x = 4/9.

**Example:** Write 2.363636... as p/q.

Let x = 2.363636...
Then 100x = 236.3636... = 234 + x
So 99x = 234, giving x = 234/99 = 26/11.

**Example:** Write 0.7282828... as p/q.

Let x = 0.7282828...
Then 100x = 72.82828... = 72.1 + x
So 99x = 721/10, giving x = 721/990.

### A surprising fact

0.9999... = 1 (exactly!). Let x = 0.9999..., then 10x = 9.9999... = 9 + x, so 9x = 9, hence x = 1.

### When does a rational number give a terminating decimal?

A rational number p/q (written in simplest form) has a terminating decimal if and only if every prime factor of q is either 2 or 5 (or both).

## Operations on Real Numbers

Rational numbers are **closed** under addition, subtraction, multiplication, and division (except by zero). The rules for irrational numbers are a bit more nuanced.

**Key results to remember:**

1. **Adding or subtracting** a rational number and an irrational number always gives an **irrational** result.
2. **Multiplying or dividing** a non-zero rational number by an irrational number always gives an **irrational** result.
3. When you combine two irrational numbers (add, subtract, multiply, or divide), the result **could be either** rational or irrational.

**Examples:**

* sqrt(5) + (-sqrt(5)) = 0 (two irrationals giving a rational)
* sqrt(3) times sqrt(3) = 3 (two irrationals giving a rational)
* 3 + sqrt(7) is irrational
* 5 times sqrt(2) = 5sqrt(2) is irrational

### Identities with square roots

For positive real numbers a and b:

1. sqrt(ab) = sqrt(a) times sqrt(b)
2. sqrt(a/b) = sqrt(a) / sqrt(b)
3. (sqrt(a) + sqrt(b))(sqrt(a) - sqrt(b)) = a - b
4. (a + sqrt(b))(a - sqrt(b)) = a^2 - b
5. (sqrt(a) + sqrt(b))^2 = a + 2sqrt(ab) + b

**Example:** Simplify (sqrt(3) + sqrt(11))(3 + sqrt(3))
\= 3sqrt(3) + sqrt(9) + 3sqrt(11) + sqrt(33)
\= 3sqrt(3) + 3 + 3sqrt(11) + sqrt(33)

**Example:** Simplify (sqrt(13) - sqrt(5))(sqrt(13) + sqrt(5))
\= 13 - 5 = 8

## Rationalising the Denominator

When a denominator contains a square root, we transform the expression into an equivalent one with a **rational denominator**. This process is called **rationalising the denominator**.

**Example:** Rationalise 1/sqrt(3)

Multiply top and bottom by sqrt(3):
1/sqrt(3) = sqrt(3)/3

**Example:** Rationalise 1/(3 + sqrt(5))

Multiply by (3 - sqrt(5))/(3 - sqrt(5)):
1/(3 + sqrt(5)) = (3 - sqrt(5))/(9 - 5) = (3 - sqrt(5))/4

**Example:** Rationalise 1/(5 + 2sqrt(3))

Multiply by (5 - 2sqrt(3))/(5 - 2sqrt(3)):
1/(5 + 2sqrt(3)) = (5 - 2sqrt(3))/(25 - 12) = (5 - 2sqrt(3))/13

> **Key idea:** To rationalise 1/(a + sqrt(b)), multiply by (a - sqrt(b))/(a - sqrt(b)). The denominator simplifies to a^2 - b, which is rational.

## Laws of Exponents for Real Numbers

The exponent rules you already know for whole number powers extend naturally to **real number bases and rational exponents**.

### Definitions

For a positive real number a and positive integer n:

* **n-th root:** a^(1/n) is the positive number b such that b^n = a.
* **Rational exponent:** For co-prime integers m and n (n > 0), a^(m/n) = (a^(1/n))^m = (a^m)^(1/n).

### The four laws

For a > 0 (a real number) and rational numbers p and q:

1. **a^p times a^q = a^(p+q)**
2. **(a^p)^q = a^(pq)**
3. **a^p / a^q = a^(p-q)**
4. **a^p times b^p = (ab)^p**

### Worked examples

**Find 81^(1/2):**
81 = 9^2, so 81^(1/2) = 9.

**Find 243^(1/5):**
243 = 3^5, so 243^(1/5) = 3.

**Find 27^(1/3):**
27 = 3^3, so 27^(1/3) = 3.

**Find 4^(3/2):**
4^(3/2) = (4^(1/2))^3 = 2^3 = 8.

**Find 243^(2/5):**
243^(2/5) = (243^(1/5))^2 = 3^2 = 9.

**Find 81^(3/4):**
81^(3/4) = (81^(1/4))^3 = 3^3 = 27.

**Simplify 3^(2/5) times 3^(3/5):**
\= 3^(2/5 + 3/5) = 3^1 = 3.

**Simplify 5^(1/3) / 5^(1/2):**
\= 5^(1/3 - 1/2) = 5^(-1/6).

**Simplify 13^(1/4) / 13^(1/8):**
\= 13^(1/4 - 1/8) = 13^(1/8).

**Simplify 7^(1/3) times 11^(1/3):**
\= (7 times 11)^(1/3) = 77^(1/3).

## Summary

1. A **rational number** is one that can be expressed as p/q where p, q are integers and q is not 0.
2. An **irrational number** cannot be written in the form p/q.
3. The decimal expansion of a rational number is either **terminating** or **non-terminating recurring**.
4. The decimal expansion of an irrational number is **non-terminating non-recurring**.
5. Together, all rational and irrational numbers constitute the set of **real numbers (R)**.
6. If r is rational and s is irrational, then r + s, r - s are irrational; rs and r/s (r not 0) are irrational.
7. For positive real numbers a and b: sqrt(ab) = sqrt(a)sqrt(b); sqrt(a/b) = sqrt(a)/sqrt(b).
8. To rationalise 1/(a + sqrt(b)), multiply by (a - sqrt(b))/(a - sqrt(b)).
9. Laws of exponents: a^p times a^q = a^(p+q); (a^p)^q = a^(pq); a^p/a^q = a^(p-q); a^p times b^p = (ab)^p.
