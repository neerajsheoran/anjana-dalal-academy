## Key Concepts

- **Natural numbers (N):** 1, 2, 3, ... -- the counting numbers
- **Whole numbers (W):** 0, 1, 2, 3, ... -- natural numbers plus zero
- **Integers (Z):** ..., -2, -1, 0, 1, 2, ... -- whole numbers plus negatives
- **Rational numbers (Q):** numbers expressible as **p/q** where p, q are integers and q ≠ 0
- **Irrational numbers:** cannot be written as p/q; their decimals are **non-terminating and non-recurring**
- **Real numbers (R):** all rational + all irrational numbers; they fill the entire number line
- Every number set nests inside the next: N ⊂ W ⊂ Z ⊂ Q ⊂ R
- Between any two rational numbers, there are **infinitely many** rational numbers
- Rational decimals are either **terminating** or **non-terminating recurring**
- p/q (simplest form) terminates only if prime factors of q are **2 or 5** (or both)
- **Rational + Irrational = Irrational**; **(non-zero) Rational × Irrational = Irrational**
- Two irrationals combined can give rational or irrational results
- **Rationalising the denominator:** multiply by the conjugate, e.g. 1/(a + √b) × (a - √b)/(a - √b)
- **Square root identities:** √(ab) = √a × √b; √(a/b) = √a / √b; (√a + √b)(√a - √b) = a - b
- **Laws of exponents** hold for real bases and rational powers: a^p × a^q = a^(p+q), (a^p)^q = a^(pq), a^p / a^q = a^(p-q), a^p × b^p = (ab)^p

## Important Definitions

| Term | Meaning |
|------|---------|
| **Rational number** | A number that can be written as p/q (q ≠ 0, p and q integers) |
| **Irrational number** | A number that cannot be written as p/q for any integers p, q |
| **Real number** | Any rational or irrational number |
| **Terminating decimal** | Decimal that ends after a finite number of digits |
| **Non-terminating recurring decimal** | Decimal that repeats a block of digits endlessly |
| **Rationalising the denominator** | Removing the square root from the denominator of a fraction |

## Remember These

- 0.9999... = 1 (exactly) -- a common exam trick
- A terminating decimal p/q requires q to have **only** 2 and 5 as prime factors
- When rationalising 1/(√a + √b), multiply top and bottom by (√a - √b) -- denominator becomes a - b
- a^(1/n) means the **n-th root** of a; a^(m/n) = (a^(1/n))^m
- √2, √3, √5, π are all irrational -- memorise these common examples
