## Sharing Equally

Ananya and her cousin Rohan got **one dosa** from Dadi. But there is only one dosa and two hungry children! How should they split it?

If Ananya takes a big piece and Rohan gets a tiny piece, Rohan will say: "That is **not fair**!"

For a fair share, both pieces must be **exactly the same size**. When everyone gets the same amount, we call it **equal sharing**.

> **Try this:** Take a square piece of paper. Can you fold it so that both parts are exactly equal? Place one part on top of the other -- if they match perfectly, you have shared equally!

## What is a Half?

When you split **1 whole** thing into **2 equal parts**, each part is called a **half**.

```
+----------+----------+
|          |          |
|  Half    |   Half   |
|          |          |
+----------+----------+
     One Whole
```

**2 halves put together make 1 whole.**

### Seeing halves around us:

- Fold a **chapati** into 2 equal parts -- each part is a **half**.
- Break a **Parle-G biscuit** in the middle -- each piece is a **half**.
- A cricket ground divided by the pitch -- each side is roughly a **half**.

> **Remember:** Both parts must be **equal**. If one piece is bigger than the other, neither piece is a true half!

## Different Ways to Make a Half

A shape can be split into two equal parts in **more than one way**:

**Think of a rectangular card:**

```
Across the middle:    Down the middle:     Corner to corner:
+----------+        +-----+-----+        +----------+
|          |        |     |     |        |  \       |
+----------+        |     |     |        |     \    |
|          |        |     |     |        |        \ |
+----------+        +-----+-----+        +----------+
```

Every single way gives you **two equal halves** -- the shapes look different, but both pieces have the same area!

## Half and Double

**Half** and **double** are like opposite actions.

- Finding **half** means **dividing by 2**.
- Finding **double** means **multiplying by 2**.

So:
- **5** is **half** of **10** (because 10 / 2 = 5).
- **10** is **double** of **5** (because 5 x 2 = 10).

| Number | Its Half | Its Double |
|:------:|:--------:|:----------:|
| 4 | 2 | 8 |
| 6 | 3 | 12 |
| 8 | 4 | 16 |
| 10 | 5 | 20 |
| 12 | 6 | 24 |
| 14 | 7 | 28 |

> **Quick trick:** To find the half of a number, just think -- "What number do I add to itself to get this?" Half of 16? That is 8, because 8 + 8 = 16.

## What is a Quarter?

When you split **1 whole** thing into **4 equal parts**, each part is called a **quarter**.

```
+------+------+
|      |      |
|  Q   |  Q   |
|      |      |
+------+------+
|      |      |
|  Q   |  Q   |
|      |      |
+------+------+

Q = Quarter
4 quarters = 1 whole
```

Imagine a **laddoo** pressed flat and cut into 4 equal pieces. Each piece is **one quarter** of the whole laddoo.

> **Think about it:** A quarter is the same as **half of a half**! Take a paper, fold it in half, then fold that half in half again -- open it up and you see 4 equal parts.

## Halves and Quarters Together

| Divided into | Each part is called | How many make one whole? |
|:------------:|---------------------|:------------------------:|
| 2 equal parts | **Half** | 2 halves = 1 whole |
| 4 equal parts | **Quarter** | 4 quarters = 1 whole |

Here is a helpful way to picture quarters:

| Quarters | What it means |
|:--------:|---------------|
| 1 quarter | One piece out of four equal pieces |
| 2 quarters | Same as one half (because 2 out of 4 = half) |
| 3 quarters | Three pieces out of four equal pieces |
| 4 quarters | The full thing -- the whole! |

```

              (= one half)                 (= one whole)
```

## More Than Half or Less Than Half?

Look at a shape that is partly shaded. Ask yourself: is the shaded area **more than half**, **less than half**, or **exactly half**?

- If the shaded part is **bigger** than the unshaded part --> **more than half**.
- If the shaded part is **smaller** than the unshaded part --> **less than half**.
- If both parts are the **same size** --> **exactly half**.

> **Example:** Rohan ate a barfi from three sides, leaving only a small corner piece. He ate **more than half** the barfi!

## Fair Sharing in Real Life

Fair sharing means every person gets an **equal amount**.

- **2 sisters** share a mango: each gets **half** (1 out of 2 equal pieces).
- **4 cousins** share a cake: each gets a **quarter** (1 out of 4 equal pieces).
- **10 toffees** shared between 2 friends: each gets **5 toffees** (half of 10).

> **Golden rule:** Fair sharing = Equal sharing. Nobody gets more, nobody gets less!

## Key Words to Remember

| Word | Meaning |
|------|---------|
| **Whole** | The complete thing before it is divided |
| **Half** | One of 2 equal parts of a whole |
| **Quarter** | One of 4 equal parts of a whole |
| **Equal parts** | Pieces that are exactly the same size |
| **Fair share** | When every person gets the same amount |
| **Double** | Two times a number (double of 7 is 14) |
| **Half of a number** | A number divided by 2 (half of 14 is 7) |
