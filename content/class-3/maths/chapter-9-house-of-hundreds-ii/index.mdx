## Numbers Beyond 500

We have already worked with numbers up to 500. Now let us go further -- all the way to **1000**!

```
500 --- 600 --- 700 --- 800 --- 900 --- 1000
```

Here are the **hundreds** after 500:
- **600** = Six Hundred
- **700** = Seven Hundred
- **800** = Eight Hundred
- **900** = Nine Hundred
- **1000** = One Thousand (this is the same as 10 hundreds!)

> **Did you know?** The Konark Sun Temple in Odisha has **12 pairs of carved stone wheels** -- one pair for each month. If a craftsman carved **847 designs** on the temple walls, that number has 8 hundreds, 4 tens, and 7 ones!

## Numbers on the Number Line

Every number has a spot on the **number line**, sitting between two neighbours.

```
500---520---540---560---580---600---620---640---660---680---700
                                              |
                                             653
```

**653** lives between **650** and **660**.

### Finding where a number sits:

| Number | Between which hundreds? | Between which tens? |
|:------:|:-----------------------:|:-------------------:|
| 527 | 500 and 600 | 520 and 530 |
| 684 | 600 and 700 | 680 and 690 |
| 749 | 700 and 800 | 740 and 750 |
| 915 | 900 and 1000 | 910 and 920 |

> **Shortcut:** Look at the hundreds digit to find which hundreds the number is between. Look at the tens digit to find which tens it is between.

## Number Patterns

Numbers love to follow **rules**. Can you spot the rule and guess what comes next?

**Going down by 2:**
```
1000, 998, 996, 994, 992, 990, ...
```

**Going up by 10 from 630:**
```
630, 640, 650, 660, 670, 680, 690, ...
```

**Going up by 100 from 125:**
```
125, 225, 325, 425, 525, 625, 725, 825, ...
```

**Going up by 25 from 800:**
```
800, 825, 850, 875, 900, ...
```

> **Hint:** Check how much each number changes from the one before. Is it going up by 5? By 10? By 25? That rule is the pattern!

Every number can be written in **many different ways**:

**The number 542:**

| Way to write it | Number sentence |
|-----------------|-----------------|
| Hundreds, tens, ones | 5 hundreds + 4 tens + 2 ones |

**The number 300:**

| Way | Number sentence |
|-----|-----------------|

## Special Number Patterns

### Hundreds:
```
100, 200, 300, 400, 500, 600, 700, 800, 900, 1000
```

### Climbing numbers (each digit is 1 more than the last):
```
123, 234, 345, 456, 567, 678, 789
```

### Sliding numbers (each digit is 1 less than the last):
```
321, 432, 543, 654, 765, 876, 987
```

### Same-digit pairs:
```
11, 22, 33, 44, 55, 66, 77, 88, 99
```

### Same-digit triples:
```
111, 222, 333, 444, 555, 666, 777, 888, 999
```

### Palindrome numbers (read the same forwards and backwards):
```
121, 131, 141, 252, 363, 474, 585, 696, 707, 818, 929
```

## Making Numbers with Chits

Suppose you have **6 small chits**. On each chit you write either **100**, **10**, or **1**:

| Chits used | Number formed |
|---|:---:|
| 6 chits of 100 | 600 (the biggest!) |
| 4 chits of 100, 2 chits of 10 | 420 |
| 3 chits of 100, 2 chits of 10, 1 chit of 1 | 321 |
| 1 chit of 100, 3 chits of 10, 2 chits of 1 | 132 |
| 6 chits of 1 | 6 (the smallest!) |

## Bhutasankhya: Word Numerals

In ancient India, scholars used **everyday words** to stand for numbers! This system is called **Bhutasankhya**.

| Word | Number | Reason |
|------|:------:|--------|
| Moon (Chandra) | 1 | We see 1 moon in the sky |
| Eyes (Netra) | 2 | We have 2 eyes |
| Tri kala (Past, Present, Future) | 3 | Time has 3 parts |
| Disha (Directions: N, S, E, W) | 4 | There are 4 main directions |
| Pancha Tattva (Five elements) | 5 | Earth, water, fire, air, sky |
| Ritu (Seasons) | 6 | India has 6 seasons |
| Sapta Svara (Musical notes) | 7 | Sa Re Ga Ma Pa Dha Ni |

> **Fun fact:** Using this system, "Netra-Sapta Svara" would mean the number **27** (Eyes = 2, Sapta Svara = 7)!

## Key Words to Remember

| Word | Meaning |
|------|---------|
| **Thousand** | 1000, the same as 10 hundreds |
| **Number line** | A straight line where numbers sit in order |
| **Number pattern** | Numbers that follow a rule (like going up by 5s) |
| **Number sentence** | A way to write a number using + or - (like 500 + 42) |
| **Palindrome number** | A number that reads the same from left and right (like 474) |
| **Expanded form** | Showing a number as hundreds + tens + ones (like 500 + 40 + 2) |
| **Bhutasankhya** | An ancient Indian method of using words to represent numbers |
